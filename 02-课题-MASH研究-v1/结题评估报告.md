## 一、整体流程（八阶段闭环流水线）

```
【阶段0】病理学靶点确证                        【真实数据：GEO】
  GSE135251 (RNA-seq, 216例肝活检, Normal 10/NAFL 51/NASH 155, 含F0-F4分期)
  → Ensembl→symbol映射(UniProt, 13,160基因)
  → DESeq2式中位数比值标准化 → 向量化Welch t检验 + BH FDR
  → 输出：3,909个DEG；靶点验证表；KEGG ORA(第一名=Bile secretion通路 p=8.6e-4)
  ★ 结果：NR1H4(FXR)↓-0.285*, THRB(THR-β)↓-0.315*, ACACA(ACC1)↑+0.897***,
          ACACB(ACC2)↑+0.631** —— 三靶点策略获病理学实证
     阳性对照基因FASN/CYP7A1/COL1A1/TNF全部符合预期方向

【阶段1-2】FXR建模数据集构建                   【真实数据：ChEMBL】
  CHEMBL2047(人源FXR, UniProt Q96RI1, assay_type=B, IC50) REST API分页下载
  → 548条原始 → 保留精确关系('=', nM) 449条 → 盐剥离/混合物剔除
  → 规范SMILES去重(重复测定取均值) 367化合物 → PAINS过滤(FilterCatalog A/B/C) -9
  → PCA/Leverage适用域过滤(h>3(k+1)/n=0.0503) -4
  → 输出：354化合物训练集(pIC50 3.38-9.96) + AD参照基准(供天然产物域外预警)

【阶段3】贝叶斯GNN构建与评估                   【含3项方法学改进】
  GIN(3层×96维)+双头输出(μ, logσ²)
  改进①: 异方差NLL损失(偶然不确定性) + MC Dropout T=50(认知不确定性)
  改进②: 五种子深度集成稳定σ
  改进③: 双划分评估协议(随机划分=申报书标准 / 骨架划分=严格化学空间外推测试)
  加权损失(长尾补偿, pIC50<5有87个/>9仅13个)
  → 输出：随机划分 R²=0.790/RMSE=0.723/回归ECE=0.029/95%覆盖率0.94
          骨架划分 R²=-0.610(所有模型崩塌, RF R²=0.047, XGB=-0.127)
          Spearman(σ,|误差|)=0.340 —— σ确实预示误差
          分类维度: AUPRC=0.955, AUC=0.969, F1=0.917 (pIC50≥6.5二值化)

【阶段4】天然产物库构建                        【真实数据：文献调研+PubChem】
  10味保肝中药(文献交叉确认, PMC锚点) 233个成分条目
  → PubChem PUG-REST按名解析224个(每成分记录CID, 可溯源)
  → RDKit ADMET过滤(150<MW<500, LogP<5.5, HBD≤5, HBA≤10)
  → 申报书排除清单逐条执行(经典黄酮/多酚酸/泛活性骨架/雷公藤毒性成分)
  → 输出：131化合物×10味药(柴胡3/雷公藤2为苷类MW超标与毒性排除的合理结果)

【阶段5】批量推理与三级置信标注
  生产模型=全数据(354)重训五种子集成 → MC推理(T=50) → μ±σ
  双层适用域(申报书创新点③): 2D描述符leverage层 × 非线性σ层
  → 输出：域内高置信72 / 域内低置信32 / 域外预警27
          高置信TOP=黄连异喹啉生物碱群(小檗碱μ=8.21)与五味子木脂素

【阶段6】分子对接验证                          【AutoDock Vina 1.2.5官方发行版】
  5受体: 3FLI(FXR)/1OSH(FXR)/3GWS(THRβ)/5KKN(ACC2)/3GID(ACC2)
  ProDy清洗单链 → meeko制备(Gasteiger) → 盒子=共晶配体质心±(跨度+10Å)
  ①重对接验证门控: 33Y RMSD=1.22Å, T3=0.42Å, 6U3=0.76Å, S1A=0.33Å —— 全部<2Å✓
  ②阳性对照8个: GW4064(-9.70)≈丹参酮IIA(-9.73)>CDCA(-8.70)>OCA(-6.77);
    resmetirom(-10.11)>T3(-9.52); ND-646(-10.52) —— 药理学排序合理✓
  ③NP批量对接: 131×2靶点=262次(ACC最强-11.61, THRβ最强-10.28)
  ④FXR交叉对接(机理佐证): CW-BCS前10在两FXR晶体-8.5~-10.6 kcal/mol,
    Spearman(GNN μ, Vina ΔG)=-0.394 —— 数据驱动预测与物理对接方向一致✓

【阶段7】CW-BCS评分与中药排名                  【申报书创新点②】
  CW-BCS = [(w·s_FXR)·s_THRB·s_ACC]^(1/3), w=1/(1+σ), 三靶点min-max归一化
  + Tanimoto结构冗余惩罚 + 绝对活性标志层(FXR μ≥6.5 或 ΔG≤-7)
  → 输出：中药排名前5 = 黄连(0.718) > 苦参(0.585) > 甘草(0.566)
          > 雷公藤(0.565) > 丹参(0.545)
          四维结果表(中药-成分-三靶点-置信度) 131行完整CSV
          黄连碱族三靶点全覆盖(FXR 8.44/THRβ -8.46/ACC -10.40)

【阶段8】可解释性与成图交付
  GNNExplainer: 小檗碱族关键原子=季铵N+异喹啉芳香核(药效团合理)✓
  6张图(校准图包/靶点箱线图/火山图/中药排名图/ORA图/三级标注图) + 15张数据表
```
