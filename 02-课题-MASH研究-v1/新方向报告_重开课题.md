## 一、新方法学框架（顶刊逻辑，8步）

```
①遗传学锚靶(GWAS Catalog+Open Targets实测) → ②疾病模块(216例共表达)
→ ③超大天然库(COCONUT 73.9万分子,含物种/文献) → ④多靶点QSAR(11肝靶点,9195化合物训练)
→ ⑤冷门来源+ADMET+新颖性过滤 → ⑥综合分排名 → ⑦对接三角验证 → ⑧湿实验方案
```

与原方法的本质区别：靶点不再预设FXR为主锚，而由**人类遗传学+疾病模块**决定；
化合物不再限于10味药，而是**全天然产物空间**（73.9万）；证据不再单链，而是
"遗传-表达-配体-来源"四维三角。

## 六、湿实验方案（可直接执行）

**阶段1：细胞水平初筛（HepG2/AML12脂变模型）**
- 模型：HepG2或Hepa1-6，0.25mM棕榈酸/油酸(2:1)诱导24-48h
- 化合物：TOP40（优先樟芝群+内生真菌群+海绵群各取代表，纯品可购或菌丝体发酵来源）
- 浓度：0.1/1/10/30 μM四点；DMSO≤0.1%
- 读出：①BODIPY 493/503荧光或TG定量试剂盒(主要终点)；②CellTiter-Glo活力(≥80%合格)；
  ③qPCR验证模块基因(FASN/SQLE/COL1A2/TNF)
- **Hit标准：TG较模型组下降≥30%且活力≥80%的最低浓度≤10μM**
- 阳性对照：AICAR(2mM)/小檗碱(10μM)/lovastatin(1μM)（SQLE/HMGCR模块验证）
- 阴性对照：等浓度DMSO

**阶段2：机制归属（对hit执行）**
- MARC1酶活抑制试验(重组人MARC1, cytochrome b5还原系统, 检测NADH消耗340nm)
- FXR报告基因(SRC-1共激活)/THRβ报告基因验证QSAR预测方向
- 荧光偏振或SPR验证结合(KD)

**阶段3：体内验证（1个最佳hit）**
- C57BL/6J雄性, AMLN饮食12周造模+4周给药(20mg/kg/day灌胃)
- 终点：肝重/体重、HE+油红O、NAS评分、qPCR纤维化基因、血清ALT/AST
- 统计：每组n=8，双因素ANOVA

**采购/获取现实性**：樟芝成分（菌丝体发酵粉可得，antrodin HPLC标样可购）；
内生真菌来源可委托高校菌种保藏中心发酵获取；海绵来源建议先用全合成类似物或跳过。
