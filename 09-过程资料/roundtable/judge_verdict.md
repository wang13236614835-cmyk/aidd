## 一、复算裁决记录（争议数字逐项实测）

原始数据：`mash_research/results/tables/gnn_metrics_v2.json`（含 random/scaffold 两组 test_preds：y/mu/sigma，n=36/34）、`results/v5/final_unified_scores.csv`、`results/tables/herb_cwbcs_ranking.csv`。复算工具：Python（排序平均处理并列的 Spearman 手写实现，R²=1−SS_res/SS_tot）。复算日期 2026-08-23。

### a. σ 与 |误差| 的 Spearman（随机 vs 骨架）

**裁判实测**（对 json 内自带 test_preds 逐点复算）：

| 口径 | 随机划分 (n=36) | 骨架划分 (n=34) |
| :--- | :--- | :--- |
| **测试集 σ vs \|err\|** | **+0.5853**（t=4.21，p≈2e-4，显著） | **+0.2688**（t=1.58，p≈0.12，不显著） |
| 测试集 σ vs 带符号 err | −0.1454 | −0.2244 |
| json 存储值 Spearman_sigma_err | +0.3404 | **−0.0268** |
| 95% 覆率（测试集 1.96σ 复算） | 1.0000 | 0.7353 |
| 95% 覆率（json 存储值） | 0.9437 | 0.8000 |

**裁决**：
1. 正方三个复算数字 **+0.585 / +0.269 / −0.224 全部与裁判实测吻合**（含 p 值量级）。
2. json 存储值（random 0.340 / scaffold −0.027）确实与 test_preds 口径不符——裁判另发现覆率同样不符（test-only 0.735 vs 存储 0.80），佐证存储值为**另一口径**；且 FINAL_REPORT 第95行原文自注"0.340（pooled val+test n=71）"，即存储值口径有据可查。反方 −0.027 是 json 真实存储值、**非捏造**，但把它当作测试集口径并推出"σ在外推中完全失效"，与 test-only 复算（+0.269，方向为正）不符；正方"σ在外推显著有效"同样不成立（n=34，p=0.12）。
3. **数字来源之争：正方胜；"完全失效"论断：反方不成立；确凿事实是骨架 95% 覆率 0.80（test-only 更差为 0.735）——σ 域外欠膨胀，此项反方实质正确。**

### b. "掐头去尾后 R²=−10.04" 属于哪个划分

**裁判实测**（按 y 排序去头去尾各 k 个，两划分对照）：

| k | 随机划分 R² | 骨架划分 R² |
| :--- | :--- | :--- |
| 5 | +0.526 | −4.231 |
| **7** | **+0.410**（按 μ 掐 +0.349） | **−11.111** |
| 8 | +0.299 | −15.854 |

**裁决**：随机划分掐头去尾各7后 R²=**+0.41**（与正方一致，且 k=5/8 全程为正）；−10.04 量级的负值**只能复现于骨架划分**（裁判实测 −11.11，与反方 −10.04 同源同量级）。反方 R1 将骨架划分的算术安在"0.79 随机划分"头上并据此称"0.79 纯靠宽量程撑起"——**归属错误，正方胜**。需如实记录的反方残余合理性：掐头去尾确实使随机 R² 从 0.79 降至 0.41，"宽量程有贡献"方向上并非全无道理，但"纯靠"不成立。反方至 R2 未撤回此条。

### c. 骨架划分 95% 覆率 0.80 是否属实

**裁决**：json 存储值 scaffold coverage[95%]=0.800，属实；裁判 test-only 复算为 0.735，只会更差。**反方数字成立（正方已让步，让步有效）**。随机划分覆率反而过宽（存储 0.9437 / test-only 1.0），说明 σ 膨胀在域内过、域外欠——正方"σ域外欠膨胀"的诊断与反方指控在此汇合，双方实质一致。

## 二、总体裁定

**辩题答案：有条件成立——以"延续修正"为主体，但必须吸收反方三项结构性条件；条件不执行则反方"推倒重做"自动成立。**

理由骨架：复算显示正方核心资产真实且可复现（双划分协议、354清洗数据、随机划分 R²=0.790/掐后+0.41、GSE135251 四靶数字、v2 各靶指标），失败集中于**输出层与披露纪律**（无名条目、Obtain误置、n=2直排、PA药材漏滤、σ域外覆率未披露、1847、证据等级措辞）——这些恰恰全部有双方已收敛的具体修补方案。反方的系统性诊断（无外部反馈回路的计算自证）被错误模式实证，但其"推倒"药方过矫：替代方案未执行、单轴叙事自身也有"坟场"风险（ION224搁置/ervogastat两度易主，反方未正面回应）、且反方两张王牌统计数字（−0.027 的口径、−10.04 的划分归属）经复算归属有误。**"修正的成本远低于重做、且修正清单已在双方之间形成共识"是本裁决的核心依据。**

三项成立条件：
1. **输出层重建**：候选/榜单/排名/证据标注按第六节行动清单【结题交付必须】1/3/5 执行；
2. **UQ 域外校准与披露纪律**：σ×杠杆膨胀+conformal 重校准落地前，所有 σ 加权产品声明降级；报告补披露骨架 σ-err 与覆率 0.80；
3. **契约对齐与可得性优先**：结题以 v1 契约口径呈报、v2-v5 作附录；湿实验只上可购标准品。

## 五、保留分歧（记录在案，不强行裁决）

1. **骨架 σ-err 真值**：−0.027（val+test 合并，n≈71，json 存储）vs +0.269（test-only，n=34，p=0.12）——两口径并存均真实；"σ 在外推场景是否有效"需更大域外验证集方能定谳。
2. **掐头去尾 R² 的定性**：反方 −10.04 划分归属被复算否定，但"宽量程拉高 R²"的方向性主张仍有残余合理性（0.79→0.41），反方程序上已无 R3 撤回机会。
3. **CW-BCS 交付价值**：正方认为自我设界+μ/Vina Spearman −0.394 交叉佐证足够；反方认为共享活性库与物化假设使互证无效、"交付物什么都不证明"。
4. **建库哲学**：白名单反推（可得性优先）vs 冷门来源（新颖性优先）；正方"95% 从未有人测"之问反方未答。
5. **单轴深耕 vs 组合正交四轴**：双方各自引用了对方靶轴的临床失败史，均未决出优劣。
