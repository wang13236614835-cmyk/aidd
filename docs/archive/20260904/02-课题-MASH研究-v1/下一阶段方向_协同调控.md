# 下一阶段研究方向：多靶点组合协同调控抗MASH
生成：2026-08-18 | 基于前三阶段全部已验证资产 | 数据表：results/v3/combination_synergy_design.csv

## 一、阶段定位
单靶点与单分子多靶点研究已完成（前三阶段）。本阶段进入**组合协同（多组分协同调控）**：
不是找一个"万能分子"，而是设计**正交作用轴互补的组合**——各组分分别覆盖MASH不同
疾病模块，联合产生单药达不到的协同效应。载体：中药活性组分配伍（组分级，非复方煎剂）
+ 微生物/海洋来源天然组分；转化桥梁：与上市药resmetirom的组合。

## 二、协同设计原则（可计算、可验证）
1. **正交靶轴**：核受体轴(FXR/THRβ/PPARγ/LXRα) / 脂合成轴(ACC/DGAT2/SCD/HMGCR) /
   炎症间接轴(TLR4-MyD88/NF-κB) / 纤维化轴(胶原/ECM)——四轴对应GSE135251的疾病模块。
2. **低冗余**：两药覆盖轴重叠数(redundancy)越小越好，机制互补而非叠加。
3. **间接作用入列**：不直接抑制酶/受体、经免疫调节(TLR4/NF-κB)或细胞保护
   (抗缺氧/抗凋亡)起效的组分允许作为组合成员——这正是中药"调和"思想的现代化表达。
4. 协同分=Σ轴覆盖强度×(1+0.3×轴数)/(1+0.25×冗余轴数)。

## 三、组合设计结果（实测输出）

**首选二联（4轴全覆盖、零冗余，score 10.45）：**
> **Antrocinnamomin F（樟芝）+ Versicolamide B（A. versicolor预吲哚生物碱）**
> 前者主攻核受体+脂合成（5靶QSAR+三受体对接全<-8），后者提供炎症间接轴+纤维化/细胞保护轴
> （家族notoamide Q肝缺血再灌注保护先例，PMID 37560942），全合成可得。

**首选三联（四轴正交全覆盖）：**
> **Antrocinnamomin F + Alternaramide（海洋环肽，TLR4/NF-κB间接轴）+ Versicolamide B**

**转化医学桥组合：**
> **Alternaramide + resmetirom（上市THR-β激动剂）**——天然抗炎组分×获批代谢药的
> "代谢+炎症"双轴联用，对应Madrigal 2026年ervogastat联用策略的行业方向。

**中药配伍叙事组（论文用）：**
> **积雪草asiatic acid（纤维化轴）+ 黄连小檗碱（代谢+炎症已知多机制）**——
> 传统"清热配伍"现代化表达的对照组；antcin K作阳性对照锚。

其余10个组合及评分见combination_synergy_design.csv。

## 四、湿实验协同验证方案（核心）
1. **模型**：HepG2/Hepa1-6棕榈酸脂变模型（炎症轴验证加LPS共刺激RAW264.7条件培养基）。
2. **给药矩阵**：首选二联做6×6浓度矩阵（0.3-30μM各6点）+单药对照；三联先做固定比例
   (1:1:1)棋盘简化。
3. **协同度分析**：Bliss独立模型+Loewe+ZIP三法一致性（SynergyFinder标准流程）；
   **Hit标准=ZIP协同得分>10且该浓度下单药均无效**（真协同而非相加）。
4. **机制印证**：组合vs单药的qPCR/WB——SREBP1c/FASN(脂)、p-p65/IκBα(炎)、
   COL1A2/αSMA(纤维化)三模块同时下调=协同的分子证据（论文核心图）。
5. **体内**：AMLN小鼠12周+4周三联灌胃(各10mg/kg)，NAS+油红O+三模块IHC。

  Biomed Pharmacother。

## 六、风险与边界（如实）
- 组合协同预测本质是**假设生成器**，必须由ZIP矩阵实验裁决；协同分数不代表药效。
- Versicolamide家族细胞毒名声需安全窗实验先行（单药≥20μM无毒才入组合）。
- 三联体内剂量递减逻辑（各10mg/kg低于单药有效量）是协同证据的一部分，需预实验支持。
- 生物药（GLP-1类/FGF21）组合超出本科可执行范围，仅作为转化展望写入讨论。


## 七、多方独立验证裁决（2026-08-18追加，用户质询后执行）
四种独立方法复检组合设计：

| 方法 | 结果 | 与原设计的对齐度 |
|---|---|---|
| 网络医学邻近度(Guney2016/Cheng2019框架，STRING真实数据) | 含Alternaramide组合z最优(-0.90/-0.58)；Berberine单药z=-1.06最邻近 | 方向一致 |
| 临床组合先例(Web检索) | MASH组合策略被强烈认可：DUET(FXR+THRβ)/ATLAS(FXR+ACC)/TANDEM(FXR+CCR2/5)/SYNERGY(FGF21+GLP-1)均进2期 | 策略层面强支持 |
| 单细胞细胞类型证据(Nature 2019 GSE136103等) | 胶原限于间质谱系(HSC)、IL1B/CCR2限于巨噬细胞——多轴作用于不同细胞类型直接成立 | 强支持 |
| 组合数据库(DrugComb/SynergxDB/DCDB) | 无肝病数据(库以肿瘤为主)——不构成反对但无支撑 | 中性 |

**证据强度分层修正（诚实裁决）**：
- 代谢+代谢组合：证据最强（临床DUET/ATLAS/SYNERGY+动物组合数据）→ 升为一等方向
- 代谢+纤维化：中（SYNERGY阳性信号+asiatic acid直接HSC证据+胶原细胞类型学强）
- 代谢+炎症：中偏弱——机理串扰强(FXR压NF-kB, Hepatology 2009)但唯一临床硬配对TANDEM未显示增效且Alternaramide的TLR4/NF-kB身份两个代理核查结果矛盾(一处给PMID 26620692,另一处未检索到)→ 必须人工复核原文后才能作主打
- 三联：中偏弱（安全性支持、增效未证实）
- Versicolamide B肝细胞保护身份=家族先例(notoamide Q IRI)非本体证据→降级为需实验确认

**修正后推荐组合**：
1. Antrocinnamomin F + asiatic acid（代谢+纤维化，SYNERGY范式，组分身份证据均直接）
2. Antrocinnamomin F + Butyrolactone VI轴内递进（代谢+代谢，最强证据档）
3. 含Alternaramide组合降为二线，待PMID 26620692原文人工复核+NF-kB报告基因确认后再升级
（原首选樟芝+Versicolamide B组合的Versicolamide B身份待实验确认，暂缓）
