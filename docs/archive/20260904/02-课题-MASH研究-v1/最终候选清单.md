# 最终候选清单：可直接使用的抗MASH药材成分（2026-08定稿）

## 一等（证据最全，可立即采购进入湿实验）
1. 樟芝 antcin K / antrodin B / Antrocinnamomin F —— 唯一"临床RCT+两条独立计算路线+三受体对接"三重命中
   · 来源有NASH小样本RCT(28例双盲, PMID 32657670)；无任何国家批准药品
   · 5靶点QSAR + FXR/ACC/THRβ对接全<-8；获取：樟芝菌丝体发酵粉+标样可购
2. 积雪草 asiatic acid —— 纤维化轴，直接文献(TGFβ/Smad+HSC抑制, PMID 35963324)，商品化，肝方向无上市药

## 二等（新颖性最高，需发酵/复核后跟进）
3. 土曲霉 Butyrolactone VI / Aspernolide D —— 5靶QSAR+FXR/ACC对接强，极易发酵
4. Alternaramide(海洋环肽) —— TLR4/NF-κB轴，身份需NF-κB报告基因裁决
5. Versicolamide B —— 有全合成路线(Nat Chem 2009)

## 最终推荐给药方案（组合协同）
- 首选组合A：Antrocinnamomin F + asiatic acid（代谢+纤维化，SYNERGY临床范式）
- 首选组合B：Antrocinnamomin F + Butyrolactone VI（代谢+代谢，最强证据档）
- 阳性对照：antcin K / 小檗碱
