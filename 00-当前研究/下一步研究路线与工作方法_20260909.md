# 下一步研究路线与工作方法（2026-09-09）

**定位**：承接 2026-09-09 两轮工作——①DockScope 平台验证（`validation/dockscope_verify_20260909/`，三靶门控+多种子证据）与 ②54 条 NP 库×3 靶 162 次对接初筛（`screening_dry_20260909/`，moracin N 三靶第一、13 条三靶一致）。本文给出第二阶段（核查→稳健性→短名单→验证准备）的可执行路线。**AI 辅助起草，采信与推进需组内/导师复核**；`candidate_release` 维持 false。

## 一、三层产出的区别（先说清概念，避免越级表述）

| 层级 | 定义 | 现状 | 证据要求 |
|---|---|---|---|
| **L1 当前计算命中榜** | 单一方法（Vina 1.2.7，固定晶体盒，seed42）对 54 条库的分靶排序 + 多种子复核的名次稳定性 | **已有**（初筛+本阶段多种子复核） | 纯计算；只支持"方法内排序假设"，不支持活性/亲和力/药效 |
| **L2 待核查短名单** | L1 中通过：跨种子排名稳定 + Tier B 身份人工核查 + PAINS/聚集筛查 + 文献先验不冲突 + 受体 Tier B 审查的子集 | **未产生**（本阶段任务，标准见§六） | 计算稳健 + 可追溯身份 + 无反向先验；仍非候选药物 |
| **L3 真正候选药物** | L2 中通过：正交方法一致性（不同打分函数/MD）+ **至少一种实验证据**（FXR 报告基因/结合测定）+ 导师签核 | **不存在**；湿实验按项目状态"conditional_after_dry_gates"不自动启动 | 实验活性 + 方向（激动/拮抗）+ 签核记录 |

**当前任何一条（包括 moracin N）都只处于 L1。**把对接分当跨靶亲和力或药效、预设 moracin N 必然获选，均违反本项目证据规范。

## 二、论文主线与探索分支的衔接

**主线**：FXR/GNN/CW-BCS 中文核心投稿（V1，首投目标 2026-12-15，硬期限 2027-02-01）。
**探索分支**：THRB/FASN 多靶对接（本阶段新增的三靶一致名单）。

衔接方式（三层）：

1. **数据层**：三靶共用同一验证过的工具链（DockScope vina.exe e0c4b271…、RDKit 2026.03.3/meeko 0.7.1、固定晶体盒协议）；FXR 榜直接进入主线材料，THRB/FASN 榜作为"跨靶一致性"附录数据集；
2. **方法学层**：FASN 双盆地发现（§四-3）、daidzein 对接-报告基因张力（§四-4）写入主稿讨论——它们是"对接分数局限"的实证素材，强化主稿方法学严谨性；
3. **叙事层**：主稿主张 FXR 计算筛选方法学；THRB/FASN 不进入主稿结果章（THRB 的 MASH 相关性 meta FDR=0.336 不显著=审计 A05；FASN 门控界缘），仅在讨论/附录说明探索边界，**防止重蹈"THRB 静默提主线"的范围错误**（2026-09-05 已纠正过一次）。

## 三、两条路线比较与推荐

| 维度 | 路线 A：聚焦 FXR（主线优先） | 路线 B：多靶探索（FXR+THRB+FASN 并行） |
|---|---|---|
| 靶点证据 | FXR 门控 0.735/0.838 Å 两轮通过；疾病生物学最强（OCA 等 FXR 激动剂已到 NASH 3 期） | THRB 门控最稳（5/5，0.61–0.73 Å）但 **MASH 相关性 meta FDR 不显著（A05）**；FASN 门控界缘（双盆地，1/4 种子过） |
| 命中物先验 | formononetin 有 NASH 体内药效 + SIRT1-FXR 文献（先验最强）；daidzein 报告基因阴性（反向案例也有方法学价值） | moracin N 三靶第一但零靶点文献；THRB 方向（激动 vs 拮抗）未定（审计项 09） |
| 验证成本 | 单靶闭环：正交重打分 + 1 种报告基因实验即可回答方向 | ≈3× 成本；THRB 需先补激动/拮抗方向判定；FASN 需先解决打分分辨率问题 |
| 论文贡献 | 直接服务 12 月首投（时间表紧迫） | 探索性，可作第二篇/后续课题储备 |
| 风险 | 天然产物对 FXR 多为弱/间接调节（daidzein 案例）；新颖性偏弱 | 主线化与 9/5 范围裁决冲突；证据链最长的路径 |

**推荐：路线 A（聚焦 FXR）为下一阶段主线，THRB/FASN 降级为"一致性附录+储备分支"。**
理由：① 与 9/5 既定裁决一致（不静默转 THRB），时间表硬约束下优先保首投；② FXR 是三靶中唯一"门控稳健+疾病生物学强+命中物有正面先验"俱全的靶点；③ THRB 主线化需先补 A05（相关性）与项 09（方向），FASN 需先解决双盆地打分区分度——都是未定期限的前置；④ 三靶数据不浪费：一致性名单保留为附录与储备，成本几乎为零。**若 FXR 短名单实验出阳性，再评估是否扩展多靶**（分支激活的预设条件，避免现在就并行烧资源）。

## 四、本会话首批完成结果（2026-09-09，均可复现，产物在 `screening_phase2_20260909/`）

1. **库身份 Tier A 自动核查（13/13 PASS）**：13 条三靶命中物全部通过 PubChem 名称→CID 解析、分子式一致、同分异构 SMILES 逐原子一致（含立体的 4 条糖苷/儿茶素按同分异构口径通过）。**Tier B 人工确认（药材来源真实性、分离物立体构型、复核人签核）0/13，全部待做**。→ `01_library_check/`
2. **受体 Tier A 自动审查（3/3 完成，无阻断项）**：三靶单链、REMARK 465 无缺失残基、固定盒 100% 覆盖共晶配体、pdbqt 含极性氢（THRB400/FASN484/FXR375）、口袋 4.5Å 内残基 20–29 个。**Tier B 待做**：质子化/互变异构（HIS 9–11 个/靶，PROPKA 复核）、THRB clean 删减的 107 残基内容确认、链/结构域与 MASH 细胞语境相关性。→ `02_receptor_audit/`
3. **FASN 1/4 种子过的机制分析（关键发现）**：保留全部失败种子。五个姿态（4 协议种子+1 平台）质心偏移全部 ≤0.24 Å、接触残基与晶体重叠 95–100%——**位点全部正确**；失败 3 种子收敛到同一姿态（互相 RMSD 0.09–0.25 Å），通过者与平台姿态为另一姿态（1.63/1.65 Å，互相 0.34 Å），两组姿态间 1.3 Å。结论：**同一位点双结合模式的双盆地竞争，Vina 打分对两模式区分度极小**——不是口袋错误也不是随机噪声。含义：提高 exhaustiveness 可能改善两盆地采样比较；单种子门控对 FASN 不适用；失败结果全部保留作证据。→ `03_fasn_seed_analysis/`
4. **命中物文献先验（AI 检索，需人工复核原文）**：先验梯度 formononetin（NASH 体内药效 SIRT1/PGC-1α/PPARα + TFEB 脂噬 + SIRT1-FXR 胆汁淤积改善）＞ daidzein（FXR 报告基因阴性=反向先验）＞ moracin N（三靶第一但 FASN/FXR/THRB 零直接文献）。**对接榜与文献先验不一致本身是"分数≠活性"的内部实证**。PAINS/聚集筛查（Aggregator Advisor 等）未做，列任务 T4。→ `05_literature/`
5. **13 命中物×3 靶×3 补充种子稳健性复核（T3，已完成，117/117 无失败）**：与 seed42 合并为 4 种子统计。**稳健层**（分数 sd≤0.1 kcal/mol）：moracin N（三靶 sd 0.01/0.02/0.05，三靶第一完全成立）、daidzein、formononetin、3'-methoxydaidzein、biochanin A、moracin M、capillarisin、isorhamnetin、toralactone；**中稳层**（sd 0.1–0.3）：piceid（FXR/FASN）、genistin（FASN）、daidzin（FASN）；**不稳定层**（sd>0.3，名次解释力弱）：piceid（THRB，range 2.57）、genistin（FXR/THRB）、daidzin（FXR）、epicatechin（三靶）。共性规律：**含糖基/高柔性的苷类打分波动大，苷元稳定**——S1 标准据此补充分数稳定性判据（见§六）。FASN 榜 NP 配体打分本身跨种子稳定（ZEP 界缘是共晶参照的打分分辨率问题，不影响 NP 排序解释，但 FASN 门控界缘仍须在短名单中注明）。→ `04_multiseed/multiseed_stability.csv`

## 五、工作方法（全阶段通用）

1. **证据分级**：Tier A=机器可复核（脚本+日志+哈希，自动执行）／Tier B=必须真人（来源真实性、立体构型、原文复核、签核）／Tier C=导师裁决（短名单放行、实验启动、投稿）。AI 产出一律标注"AI 辅助，待复核"。
2. **留痕规范**：每个计算产物记录输入文件 sha256、参数（种子/exhaustiveness/盒子）、引擎 sha256、时间戳、命令行；原始结果不覆盖（失败也保留）；本阶段所有产物只新增不改写 20260905 与初筛目录。
3. **复现规范**：单一入口脚本（`run_screening.py`/`multiseed_hits.py`），重跑须逐位或统计等价；同一 Vina 二进制的重跑只算**技术复现**，不作为独立方法学验证（区分记录）。
4. **统计口径**：名次稳定性用 4 种子的中位数与 IQR；不挑种子、不挑模式、不删除失败记录；多重比较不掩饰（13 条×3 靶的一致性是筛选假设，不是确证）。

## 六、短名单进入/淘汰标准（预设、透明、不针对个别化合物定制）

**进入 L2 短名单须同时满足**：
- S1 排名与分数双稳定（据 T3 实证修订）：4 种子内该靶名次中位数 ≤20 且 IQR ≤10，**且**最佳得分 sd ≤0.3 kcal/mol（sd>0.3 者标记"分数不稳定"降级为暂缓，除非人工复核给出保留理由——现有此类：piceid/genistin/daidzin/epicatechin 的部分靶点）；
- S2 身份核查：Tier A PASS 且 Tier B 完成（名称/CID/SMILES/立体与药材来源有人工签核）；
- S3 干扰筛查：PAINS/聚集（Aggregator Advisor/FAF-Drugs）无红旗，或红旗经人工裁决并注明理由；
- S4 先验不冲突：无方向明确的反向实验文献（如已知报告基因阴性则降级至"方法学案例"池并注明）；
- S5 类药底线（宽松 NP 口径，例外须注明）：MW≤600、cLogP≤6、HBD≤6、HBA≤12、rotB≤15。

**淘汰/暂缓必须逐条记录理由**，写入短名单附表（含"暂缓可复议条件"）。**moracin N 不预设获选**：当前其卡在 S2/S3/S4 均未完成。
