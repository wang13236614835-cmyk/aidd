# Moracin N 候选资格判定

**日期：2026-09-13**

## 判定：**GO**

Moracin N 值得正式进入 MASH-related hepatic validation（Gate M0→B0→1→2→3）。实验前资格验证已完成；生物学结果未执行——本判定是对"是否值得花钱进入实验"的裁决，不是对疗效的裁决。

## 一、支持 GO 的证据（逐条可溯源）

1. **分子侧直接功能证据 + ML385 药理阻断支持 NRF2 signaling involvement**：HT22 抗铁死亡 EC50<0.5 μM（PMID 34281775）；MCAO/OGD 中 Keap1/Nrf2 激活 + ML385 阻断保护（PMID 40972263）——已有直接功能证据，并有 ML385 药理阻断支持 NRF2 signaling involvement；遗传学验证（siNRF2/CRISPR）前不升因果等级，这在天然产物中仍属少见。
2. **疾病侧独立成立**：MASH 铁死亡/NRF2 防线有动物+人组织证据（PMID 31610178、36495698）；同类天然先例已证明该通路可药（hinokitiol PMID 39922149）。
3. **空白真实且可低成本裁决**：分子×肝细胞脂毒性×Nrf2 因果连接零文献（指定检索边界内）；一套 Gate 0–3（预算 ¥3685–8845 分期，Gate1 失败最大沉没 ¥3419）即可闭环。
4. **身份/物料资格 PASS**：CAS/InChIKey/SMILES 多库一致；DMSO 322 mM 实测可溶；PAINS 无警报；剂量窗双锚（<0.5 μM 活性 / >32 μM 毒性）；≥2 家供应商核实。
5. **无资格否决项**：无肝毒性记录、无 off-target 红旗（对比 3'-methoxydaidzein）；A549 反向效应已转化为设计约束（活力窗+Model-only 对照），而非否决理由。

## 二、最大风险（已对应到 Gate）

| 风险 | 对策 |
|---|---|
| 酚类探针干扰（DCFH/C11 假象） | Gate M0 六项无细胞前置；DCFH 降级 exploratory |
| 细胞类型迁移失败（神经元≠肝细胞；A549 反向） | Gate 1 活力窗判读修正；B0 换模型预案 |
| PA/OA 模型无铁死亡成分 | Gate B0 Fer-1 rescue 硬门 |
| ML385 工具药问题（剂量自设/自身毒性） | Gate 3 毒性对照+NRF2 下游读出生效证明 |
| 长期 NRF2 安全性/口服暴露 | 不在本轮主张范围；边界写入报告 |

## 三、结论等级预期管理

当前 Level 0（候选假说）；本轮后进入 L1–L3 裁决流程；**大创达到 L2–L3 即有完整价值**；Gate 3 阴性=撤销"主要介质"表述而非项目失败。
