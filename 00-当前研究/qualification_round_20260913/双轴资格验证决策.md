# 双轴资格验证决策

**日期：2026-09-13｜组合：FASN = CONDITIONAL GO + Moracin N = GO**

## 一、判定矩阵

| 轴 | 判定 | 一句话依据 |
|---|---|---|
| **FASN 长期 AIDD 主轴** | **CONDITIONAL GO** | 可学习信号真实（10 seed Ridge R² 中位 0.732，Y-scrambling 0/20 exceeded），但外部定量泛化失败（R² 0.18/分 assay 全负）且 54 天然产物全域外 → 模型限定为 canonical assay model；两条件未解前不发天然产物筛选资格 |
| **Moracin N 近期验证轴** | **GO** | 分子侧直接+ML385 因果证据、疾病侧独立成立、连接空白真实、身份/物料/预算资格全过、无否决项 → 值得正式进入 MASH 相关肝细胞验证 |

## 二、组合执行：**维持双轴（不对称投入）**

按最终战略轮规则"FASN GO/COND + Moracin N GO → 维持双轴"，但本轮新增投入比例约束：

- **近期（0–3 个月）主投入 → Moracin N 轴**：它是当前唯一能在 1–3 个月内产出真实生物学裁决的轴；预算走第六轮分期包。
- **FASN 轴转"条件解决期"**：只做两件不花钱/低花钱的事——①多 assay 融合方案设计+assay-aware 校准试点（计算）；②外部校准集锁定协议。**在条件解决前不扩库、不做天然产物预测、不训 GNN。**
- 两轴失败互不连坐（继承最终战略轮规则）。

## 三、若 FASN 条件 3 个月内未解决

FASN 轴降级为"canonical assay 方法学研究"（数据+方法学论文线仍有完整价值：provenance 审计、Y-scrambling、泄漏审计、外部失败本身就是结论），主发现权重移至 Moracin N 轴，并启动 Plan B 靶点审查（THRβ ligand-based 优先）。

## 四、本轮给项目的净变化

1. FASN 主张范围收窄但资格保住——从"可能是通用模型"变为"明确知道可信范围在哪个 assay、哪个化学域"；
2. NP54 FASN 排序资格正式冻结为"无"（0/54 域内）——这不是损失，是防止未来产出不可靠榜单；
3. Moracin N 从"证据支持的候选假说"升格为"正式实验候选"，Gate 编号体系与干扰前置全部冻结，导师批准即可执行。
