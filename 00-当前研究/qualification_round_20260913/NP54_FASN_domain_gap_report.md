# NP54 FASN 域间隙报告

**日期：2026-09-13｜结论复验成立并正式冻结**

## 一、复验结果（本轮用 canonical clean 96 分子训练域重算）

54 个天然产物到 canonical FASN 训练集的 max-Tanimoto：

- 最小 0.078；**中位 0.136**；**最大 0.171**；
- AD 阈值（训练 LOO NN 5th 百分位）= 0.812；
- **in_domain = 0/54；out_of_domain = 54/54**。

与最终战略轮历史值（中位 0.136、max 0.171）一致——复验通过，非复制误差。

## 二、域间隙的结构性原因

训练域本身是一个单文献、单系列的药物化学战役（LOO NN 中位 0.885）。天然产物不是"稍微域外"，而是与该系列几乎无结构重叠（最高 0.171 ≈ 阈值的 21%）。

## 三、冻结决定

> **当前 54 个天然产物全部属于明显 OOD / 极弱覆盖区域。**

因此：

1. **禁止输出任何形式的"FASN 活性排行榜"**（无论用哪个模型）；
2. 允许且只允许把 NP54 用作：
   - OOD challenge（展示模型拒判能力）；
   - uncertainty demonstration（域外预测区间极端膨胀/均值回归）；
   - domain-gap analysis（量化天然产物与 assay 数据的化学空间断层）；
3. 天然产物进入 FASN 定量筛选的前提不是换模型，而是**获得桥接数据并重建训练域**（见 `FASN_natural_product_bridge_set.csv` 与 `FASN_GO_NOGO.md` 条件）。

## 四、正确表述模板

允许："在 canonical CHEMBL5731051 训练域下，54/54 天然产物为域外（max-Tanimoto 中位 0.136，阈值 0.812），模型对其不提供定量预测。"

禁止："模型预测某天然产物 FASN 抑制活性为 pIC50≈6.7"（此类数字在域外仅为均值回归，无决策价值）。
