## 逐连接证据等级表

| 连接 | 证据等级 | 说明 |
|---|---|---|
| Moracin N → 抗铁死亡（神经元） | **L1 直接（细胞）** | 多读出+剂量反应 |
| Moracin N → Keap1/Nrf2 通路（脑） | **L1 直接功能 + ML385 药理阻断** | 支持 NRF2 signaling involvement；遗传学验证（siNRF2）前不升因果等级 |
| Moracin N → 直接结合 KEAP1/NRF2/GPX4 | **无证据** | 只有通路激活，无 target engagement → 禁写"靶向" |
| 肝脂毒性 → 铁死亡/脂质过氧化 | **L1 疾病侧直接** | RSL3/Fer-1/DFO/selenite 双向干预 |
| NRF2 防线 → MASH 保护 | **L1 疾病侧直接（含人组织）** | HFD+人脂肪肝样本 |
| Nrf2 抑制铁死亡 → 改善 MASH | **L1 先例（hinokitiol/baicalein）** | 可行性证明，非 Moracin N 证据 |
| **Moracin N → 肝细胞脂毒性保护** | **L0 假说（本轮目标）** | 跨细胞类型迁移假设——未验证 |
| **Moracin N → NRF2 依赖（肝细胞）** | **L0 假说（Gate 3 裁决）** | 未验证 |

## 已知反向/风险连接（必须带进实验设计）

1. A549/PC9 中 10–45 μM **促** ROS/凋亡（PMID 32477104）→ 细胞类型依赖；HepG2 属肿瘤系 → 必须设活力窗与 Model-only 对照；
2. Baicalein 先例走**巨噬细胞** Nrf2/FSP1 而非肝细胞（PMID 40803417）→ 提示铁死亡细胞类型异质性，Gate 2 需 Fer-1 系统对照；
3. 酚类化合物可直接淬灭 DCFH-DA/干扰 C11-BODIPY → Gate M0 无细胞前置。

## 结论

桥接逻辑成立且有直接功能+药理阻断文献支撑两端（遗传学确证前不写因果已证实），但**中间"肝细胞迁移"环节为零证据**——这正是 Gate 1–3 要裁决的唯一科学问题，也是本候选的创新点所在。
