# Moracin N 正式 Gate 方案 vFinal

**日期：2026-09-13｜编号体系按资格验证轮重排（旧"Gate 0"拆分为 M0 物料干扰 + B0 模型资格；此后禁用旧编号指代）**

## 总览

| Gate | 问题 | 通过判据（预冻结） | 淘汰判据 |
|---|---|---|---|
| **M0** | 物料/检测是否可用 | 六项无细胞干扰测试完成且关键通道可用 | 不可排除干扰→换读数或"材料/检测不可行" |
| **B0** | PA/OA 模型是否有资格当铁死亡模型 | 脂沉积+活力合格+Fer-1 可 rescue 部分损伤 | Fer-1 无 rescue → 不得作 ferroptosis 因果模型 |
| **Gate 1** | Moracin N 有无毒窗内保护表型 | 任一浓度活力/TG/脂滴≥1 改善（不只看 TG） | 无毒窗内全部读数无改善 |
| **Gate 2** | 保护是否 ferroptosis-consistent | C11/GSH/GPX4≥2 改善且与 Fer-1 同向 | 0 机制读数改善 |
| **Gate 3** | 是否 NRF2 依赖 | ML385 削减率≥70%（+NRF2 下游读出） | 削减率<30% |

## Gate B0：模型资格（先于 Moracin N 任何结论）

- HepG2 + PA:OA(1:2) 总 1 mM BSA 偶联 24h（低成本 hepatic screening model，**禁止称完整 MASH 模型**）；
- 模型有效性：模型/空白 TG≥1.8 且模型活力≥70%；
- **铁死亡成分证明（本轮新增硬门）**：Model+Ferrostatin-1(1 μM) 组须使脂质过氧化/活力读出部分改善（rescue≥20% 方向性）；
- Fer-1 无法 rescue → 本模型只能当"脂毒性应激模型"，Gate 2/3 的 ferroptosis 表述全部降级，须换模型（AML12/L02）重过 B0。

## Gate 1：表型（修正旧设计）

- 浓度：0/0.1/0.3/1/3/10/30 μM（7 点，DMSO 恒 0.1%）；先跑无模型毒性板（30 μM 活力≥80%）；
- 读出：CCK-8 活力、细胞内 TG（蛋白归一，主端点）、油红 O；
- **判读修正（本轮冻结）**：TG 未降但活力/脂毒性保护存在 → 仍算 Gate 1 通过；**禁止用"TG 没下降=失败"作唯一判断**；反之 TG 降但活力是细胞毒性所致 → 不算通过（活力<80% 点无效）。

## Gate 2：ferroptosis 一致性

- 优先读数：C11-BODIPY 581/591（脂质过氧化）、GSH、GPX4（western/平台抗体可用时）；
- 系统对照：Fer-1 1 μM 同板（M0 已验证其自身无干扰）；
- **DCFH-DA 降级为 general ROS exploratory readout，不得单独证明 ferroptosis**（M0-4 若发现直接反应则整读数弃用）；
- 通过：≥2 机制读数改善且方向与 Fer-1 一致。

## Gate 3：NRF2 依赖性

- 四组：Model / Model+MN / Model+ML385 / Model+MN+ML385；
- **ML385 自身毒性对照必须同板**（文献摘要未给剂量，5 μM 为本项目自设，须先验证其本身不伤模型活力）；
- **新增必需项（本轮冻结）**：至少一个 NRF2 下游读出同板（NQO1 / HO-1 / GCLC / GPX4 / SLC7A11 按平台条件选一），确认 ML385 确实压制了 NRF2 信号（工具药生效证明）；
- 削减率：以 Model→MN 保护量为分母；(MN+ML385 组剩余保护)/保护量：≥70% 削减 → "Nrf2 依赖性主要介质"表述允许；30–70% → 中间带，重复或加正交；<30% → 撤销主张（候选不连带出局）；
- 条件允许后续加 siNRF2 正交（Level 4）。

## 结论等级（本方案目标映射）

- Level 0 候选假说（当前）→ L1 表型（Gate1）→ L2 ferroptosis 一致（Gate2+Fer-1）→ **L3 NRF2 依赖（Gate3）**→ L4 基因确认（siNRF2，可选）；
- 大创目标 L2–3；每级单独报告，禁止跳级合并。
