# 未来24个月路线图

## 总目标

在2028年考研前形成至少一条真实、可追溯、可重复的完整结果链，而不是追求候选数量或模型复杂度。

## 0–1个月：冻结与准备

### FASN长期主AIDD轴

- 归档全量ChEMBL和FASN_activity_master；
- 完成人工assay/document/construct抽样核验；
- 锁定canonical SPA开发集、scaffold split和UQ协议；
- 设计真正独立的external test；
- 不发布54库预测总榜。

### Moracin N近期创新轴

- 导师审批；
- COA、供应商、库存和替代读出确认；
- Gate 0无细胞干扰；
- 首批HepG2 PA/OA表型板。

## 1–3个月：第一个裁决

- FASN：判断provenance和baseline是否足以继续；
- Moracin N：完成Gate 1，决定是否进入GSH/ROS/GPX4和ML385；
- 若Moracin N Gate 1失败，保留结果并按Plan B触发规则处理；
- 若FASN数据外推初步失败，不用GNN强行补救。

## 3–6个月：验证与模型资格赛

- FASN：完成scaffold/time/external、AD、UQ和外部数据锁定；
- 仅当传统基线稳定且有明确增益时评估GNN；
- Moracin N：完成Gate 2/3和必要正交Nrf2验证；
- 需要时将Isorhamnetin作为材料替代，但先过干扰门。

## 6–12个月：第一项完整成果

### 若FASN通过

- 构建Tier 2问题导向天然产物库；
- 先测阳性参照，再做候选酶/细胞验证；
- 形成FASN数据—模型—AD/UQ—实验链。

### 若Moracin N通过

- 增加第二细胞背景；
- 形成“神经元证据→肝细胞脂毒性”的机制重定位论文初稿；
- 继续限制“完整MASH”和“直接KEAP1”表述。

### 若两者均部分通过

- 以可重复且证据层级更高的一条线为主要论文线；另一条保留为附录或方法结果。

## 12–18个月：论文和项目成果

- 形成大创结题的真实结果报告；
- 按结果决定Paper A（FASN）和Paper B（Moracin N）是否真的足以拆分；
- 只有直接酶、细胞和机制证据形成闭环时，才进行专利新用途评估；
- 不在无实验命中前申请“新药/新用途已证实”专利。

## 18–24个月：收束

- 固化GitHub版本、数据字典、模型卡、实验原始数据和失败记录；
- 完成至少一条可重复结果链；
- 研究生申请材料中如实描述：数据审计、docking门控失败、模型外推限制和功能验证结果；
- 2028年前不再开启无预注册的第三主线。

## 关键里程碑

| 时间 | 必须有的结果 | 没有时的动作 |
|---|---|---|
| 1个月 | FASN master/QC；Moracin N Gate0/审批状态 | 不采购扩展库；查清材料/人工复核阻断 |
| 3个月 | Moracin N Gate1；FASN baseline/assay判定 | 触发相应Plan B，不靠docking翻案 |
| 6个月 | FASN外部验证是否可行；Moracin N Gate3 | 冻结失败轴，选择证据更完整者 |
| 12个月 | 至少一条完整结果链初稿 | 以方法阴性或机制阴性收束，不硬凑候选 |
| 18个月 | 论文/结题版本和导师反馈 | 缩小范围，修正主张 |
| 24个月 | 代码、数据、实验和论文成果归档 | 不再增加未经验证的新方向 |
