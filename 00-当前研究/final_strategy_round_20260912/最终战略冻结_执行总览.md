# 最终战略冻结：执行总览

**版本：2026-09-12｜性质：战略冻结轮，不是候选药物放行**

## 一、最终架构

本轮在重新读取前七轮原始数据、FASN 全量 ChEMBL activity、原始关系/单位字段和实际 baseline 结果后，冻结为**双轴架构、明确主次**：

### 长期主 AIDD 研究轴

**FASN / de novo lipogenesis。**

目标是建立一个有 assay provenance、严格 scaffold/time 验证、适用域和不确定性报告的天然产物定量预测体系。当前 FASN 进入长期主轴，是“研究主轴资格”，不是“模型已经通过”，更不是“天然产物已经被预测为 FASN 抑制剂”。

### 近期高创新功能验证轴

**Moracin N → Nrf2-dependent ferroptosis regulation → MASH-related hepatic lipotoxicity。**

目标是用最小、低成本、可证伪的肝细胞实验，检验 Moracin N 已有神经元/脑缺血机制证据能否迁移到 MASH 相关肝细胞脂毒性。它承担近期创新、结题和机制结果，不承担大规模单靶点 QSAR。

两条线共同服务一个疾病问题：

> 天然产物能否分别减少异常脂质生成，或提高肝细胞对脂质过氧化损伤的防御，从而干预 MASH 相关病理过程？

## 二、本轮相对上一版结论的变更

上一版第七轮曾将 Moracin N–Nrf2/ferroptosis 作为唯一主线、FASN 作为 Plan B。本轮不机械沿用该结论，原因是重新运行了 FASN 数据和模型审计：

- 人源 FASN CHEMBL4158 全量 activity：5,541 条；
- 全量中 relation=`=` 仅 3,197 条，`<`、`>`、`<=`、`>=` 或缺失关系合计 2,344 条；
- 精确 IC50/Ki/Kd 主表：1,652 条、1,139 个分子、51 个 assay、34 个 document；
- canonical FASN SPA assay（CHEMBL5731051）：97 条记录、96 个分子、39 个 Murcko scaffold；
- 5 seed 严格 scaffold split：ECFP-XGBoost R² 中位约 0.626，ECFP-RF R² 中位约 0.336，ECFP-Ridge R² 中位约 0.736；
- 宽口径 full-length-stated time sensitivity 的 R²：ECFP-RF −0.061，ECFP-XGBoost −0.423；
- 54 个天然产物到 canonical 训练域的最大 Tanimoto 中位仅 0.136，最高约 0.171。

这些结果说明 FASN 的**数据基础明显强于 KEAP1/NRF2 直接建模假设，且比 THRβ 功能方向混合的问题更适合长期 AIDD**；同时也明确说明当前 FASN 模型不能直接放行天然产物优先级。因此最终架构改为：FASN 做长期主 AIDD 资格赛，Moracin N 做近期功能验证轴。

## 三、前七轮真正排除的东西

1. 旧 2J4A N331S TRβ discrimination gate 失败：ROC-AUC 0.346；原报告 MW 残差方向还存在符号错误。
2. WT 3GWS TRβ gate 失败：ROC-AUC 0.472，95% CI 0.341–0.607；PR-AUC 0.693，分层 AUC 0.596/0.232/0.587，方向不一致。
3. Docking 姿态恢复通过不等于活性预测通过。以后 docking 不再承担候选总榜、亲和力、激动/拮抗或亚型选择性。
4. Moracin N 不再称“TRβ 第一名”“TRβ 激动剂”或已验证药物；TRβ 只保留结构假说/临床参照/现成 reporter 裁决。
5. Formononetin 和 biochanin A 的 FXR 结合与功能身份已由 CJNM 2024 直接验证，不再包装为新发现。
6. 3'-methoxydaidzein 有 NaV1.7/1.8/1.3 亚微摩尔级本体活性及 NaV1.5 风险，不再作为高优先级药物候选。
7. 旧 FXR GNN、旧多靶 QSAR 和旧 TOPSIS/CW-BCS 排名不能直接外推到 54 个天然产物。
8. FASN 历史高分 QSAR 和旧 redock 结果不能直接作为当前模型已通过的证据。

## 四、未来 1–2 年的执行次序

### 2026-09-12 至 2026-10-12：第一阶段

- 固定本终版架构和停止线；
- 复核 `FASN_activity_master.csv`、全量 relation/censor 审计和 canonical assay；
- 不运行 GNN，不发布 FASN 天然产物总榜；
- 完成 Moracin N 采购/COA/无细胞干扰 Gate 0；
- 向导师提交一页版审批材料。

### 至 2026-12-12：三个月节点

必须得到两类结果：

1. FASN：assay-specific 数据清洗规则、baseline 复现、scaffold split、UQ/AD 和外部验证可行性判断；
2. Moracin N：至少完成 Gate 1 初步表型信号或明确记录“材料不可行/本模型未获支持”。

### 至 2027-03-12：六个月节点

- FASN 决定是否进入 Tier 2/Tier 3 天然产物库建模；
- Moracin N 若 Gate 1/2 通过，完成 ML385 因果和正交 Nrf2 验证；
- 若 FASN scaffold/time/external 仍不稳定，停止 GNN，触发 `Plan B触发条件.md`。

### 至 2027-09-12：十二个月节点

- 争取形成一个完整、可复现的 FASN 数据—模型—AD/UQ 结果包；
- Moracin N 形成机制验证报告或严谨阴性报告；
- 仅在数据和实验均支持时撰写论文/专利评估，不预先承诺“发现新药”。

### 至 2028-09-12：十八至二十四个月节点

- 完成代码仓库重构、数据版本和至少一条完整结果链；
- 根据真实结果决定拆分 Paper A（FASN）与 Paper B（Moracin N）；
- 任何未完成项目仍标为未完成，不把缺失结果写成阴性。

## 五、六个月后只能保留一条线时的客观标准

不使用综合分数。逐条记录事实：

1. 数据 provenance 是否可追溯；
2. 严格 scaffold/time/external test 是否稳定；
3. 基线是否超过均值和简单描述符；
4. AD/UQ 是否能识别域外候选；
5. 实验读出是否可重复且能被因果对照证伪；
6. 成本与平台是否在本科团队能力内；
7. 阳性和阴性是否都具有论文信息价值；
8. 是否仍围绕同一个 MASH 科学问题。

如果 FASN 只在随机 split 好、在 scaffold/time/external 失败，则不能因为“AI主线”而保留；如果 Moracin N 只有单一抗氧化读数而没有 ML385/ferroptosis 特异性支持，则不能因为“创新”而保留。

## 六、统一主张边界

允许：

- “FASN 长期 AIDD 研究轴”；
- “Moracin N 近期机制重定位验证轴”；
- “在指定 assay、split 和 AD 条件下的探索性模型”；
- “在 HepG2 PA/OA 脂毒性模型中支持或不支持 Nrf2 依赖性保护”。

禁止：

- “FASN 模型已经泛化到天然产物”；
- “Moracin N 已证实抗 MASH”；
- “Moracin N 是直接 KEAP1 配体”；
- “GNN 一定优于 RF/XGBoost”；
- “Docking 第一名所以优先”；
- “完整 MASH 模型”；
- “首次发现”“无人研究”“已发现新药”。
