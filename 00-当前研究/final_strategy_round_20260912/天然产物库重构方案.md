# 天然产物库重构方案

## 一、结论

**需要按 FASN 轴和 Moracin N 轴分层重构，但不立即扩大数量。** 现有54个分子保留为历史连续性和近期机制验证池；它不是足以支撑FASN正式虚拟筛选的代表性天然产物空间。

## 二、当前54库的事实

- 过滤后54个分子，来源为9味药材：茵陈9、山楂11、泽泻7、决明子6、葛根8、垂盆草1、叶下珠3、桑叶6、虎杖3；
- 54条结构无规范重复，但来源/部位/实验分离证据不能一概而论；
- 三靶docking已完成，但不再提供活性排序；
- 54库在 canonical FASN training set 上最大Tanimoto范围约0.078–0.171，中位约0.136；
- 该库受药材来源、性质过滤和可获得性偏倚影响，不能代表天然产物总体。

## 三、三层库结构

### Tier 1：历史54库

用途：

- 保留历史数据和候选身份；
- Moracin N、isorhamnetin、formononetin、biochanin A按各自角色进入机制/干扰实验；
- 不直接用作FASN模型训练或候选总榜。

### Tier 2：问题导向天然产物库

按明确问题扩展：

- FASN/DNL：phloretin、EGCG、kaempferol、quercetin、asiatic acid、baicalein等有直接FASN或肝脂生成线索的参照；
- Nrf2/ferroptosis：有肝细胞或MASH相关Nrf2/ferroptosis证据的天然产物；
- FXR：只保留formononetin/biochanin A等机制锚点和必要阳性对照，不再大规模重复发现。

Tier 2每个分子都要注明证据层级：纯化合物直接酶活、细胞表型、动物表型、提取物、网络药理学或仅数据库。

### Tier 3：大型参考库

可从TCMSP、ETCM、HERB、TCMID、药典、PubChem和原始植物化学文献整合，但只作参考/生成池，不能不加审计地进入候选释放。

## 四、每个库条目的最低字段

- compound_id；
- 中文名/英文名/同义词；
- CID、InChIKey、规范SMILES和立体化学；
- herb、药用部位、物种；
- 来源类型：数据库、实验分离、标准品、提取物或未知；
- 引文、PMID、DOI、数据库和检索日期；
- 目标问题：FASN、Nrf2/ferroptosis、FXR或其他；
- assay层级和结果方向；
- 纯度、供应商、货号、价格状态；
- PAINS、聚集、荧光、氧化还原、溶解度和盐/混合物标记；
- AD和预测不确定性；
- 纳入/暂缓/拒判原因。

## 五、纳入、排除和保留规则

### 纳入

- 结构和来源均可追溯；
- 问题与FASN或Nrf2/ferroptosis明确相关；
- 有可采购标准品或可通过合作获得；
- 通过基本身份和干扰审计。

### 暂缓

- 结构可用但来源、纯度、立体或供应链未闭合；
- 模型预测在域外；
- 有疾病证据但机制方向未明确。

### 拒绝

- 3'-methoxydaidzein当前NaV风险未解决；
- 盐/混合物无法拆分；
- 主要读出预计存在无法排除的光学/胶体干扰；
- 仅有docking分数、没有可检验问题。

## 六、何时重构

- 主线Moracin N Gate 0/1前：不扩大库；
- FASN数据门通过、准备建立Tier 2时：按FASN assay参照和阴性对照成套扩展；
- FASN数据门失败：不通过扩库掩盖模型失败，先转Plan B；
- 任何扩库都不能改变原54库历史记录和失败结果。
