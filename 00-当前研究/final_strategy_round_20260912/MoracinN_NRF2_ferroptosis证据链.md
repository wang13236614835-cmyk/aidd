# Moracin N–NRF2–ferroptosis 证据链

## 证据链总图

```text
桑叶直接分离的 Moracin N
        │
        ├─ 神经元 erastin：GSH↓、GPx4失活、ROS和铁积累被抑制
        │
        ├─ 脑缺血/OGD：Keap1/Nrf2激活、GSH合成↑、FTH1/ACSL4↓
        │                 ML385可阻断保护
        │
        └─────────────── 跨细胞类型迁移假说 ───────────────┐
                                                           │
MASH独立证据：肝细胞脂毒性 → 脂质过氧化/铁死亡 → 炎症/纤维化 │
MASH独立证据：NRF2–GSH–GPX4防线可缓解该损伤               │
                                                           ▼
       待验证：Moracin N是否在HepG2 PA/OA中形成同方向保护？
                              │
                 ML385/Nrf2正交干预因果裁决
```

## 分层证据

### A层：Moracin N直接实验

- HT22 erastin细胞：EC50<0.50 μM，GSH、GPx4、ROS、铁积累和相关基因读出；PMID 34281775。
- MCAO/原代神经元OGD：20 mg/kg/day脑室内给药3天，Keap1/Nrf2相关保护，ML385阻断；PMID 40972263。

### B层：MASH疾病机制

- RSL3、GPX4 activator、deferoxamine和liproxstatin-1对NASH严重程度的影响；PMID 31610178。
- HFD/人脂肪肝组织中的NRF2降低和铁死亡增强，NRF2上调保护；PMID 36495698。
- hinokitiol和baicalein等天然产物先例；PMID 39922149、40803417。

### C层：待建立的肝细胞连接

- 肝细胞中Moracin N的TG/脂滴保护；
- 肝细胞中GSH、ROS/C11-BODIPY、GPX4、SLC7A11和ACSL4变化；
- ML385削减率；
- Fer-1救援与非铁死亡抗氧化效应区分。

## 机制读出解释

- TG/油红O：表型，不等于铁死亡；
- GSH、GPX4、SLC7A11：抗氧化/谷胱甘肽防线；
- ROS/C11-BODIPY：脂质氧化读出，需注意直接光学干扰；
- ACSL4：铁死亡易感性支持读出，不是单独充分证据；
- Fer-1：系统级铁死亡参照；
- ML385：Nrf2因果阻断工具，需设置自身毒性和工具药对照。

## 为什么不把KEAP1写成直接靶点

Moracin N当前证据是通路激活和ML385阻断，并非SPR、ITC、MST、CETSA、DARTS、pull-down或target engagement。故KEAP1只能写“pathway component/upstream regulator”。

## 关键反向证据和风险

- A549/PC9等肿瘤环境中Moracin N可诱导ROS/凋亡，说明细胞类型依赖；
- 多酚/酚类可能淬灭DCFH-DA、吸光、荧光或形成胶体；
- 长期NRF2激活在肿瘤/耐药背景中可能有风险；
- 脑室内给药不等于口服肝暴露。

## 最终结论

证据链足以支持“值得做一次最小肝细胞因果验证”，不足以支持“Moracin N已抗MASH”或“直接靶向KEAP1”。成功和失败均按预注册Gate记录。
