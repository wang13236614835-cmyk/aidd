# FASN 下一道门（Gate T1）决定

**日期：2026-09-13｜承接：可迁移性报告 A2 裁决**

## 一、FASN 当前模型使用硬规则（即刻生效）

1. 只对**化学域内**查询分子输出预测：必须过 AD 检查（到 canonical 训练集 max-Tanimoto ≥ 0.812）；
2. 输出形式 = **排序 + 不确定性**；禁止输出绝对 pIC50 决策值（cal_mean 基线证明模型不含效价水平信息）；
3. 任何跨 assay 使用前必须做局部校准（该 assay ≥10 个标签分子做 offset/指示变量校准）；
4. OOD 分子（含全部 54 天然产物）一律输出"拒判/不可判"，不出排行榜。

## 二、GNN 状态

**继续关闭。**本轮证据进一步支持该决定：迁移瓶颈是"标签/assay 对齐"而不是表征能力——Ridge+小标签校准已能提取 rho 0.69 的池化排序信号；在 96 分子单系列上换架构没有可检验的增益假设。重新评估前置条件不变（多 assay 对齐数据 + 传统基线饱和）。

## 三、Gate T1：多 assay 对齐数据集组装（FASN 下一道生死门）

**问题**：现有 5,541 条 activity 分散在 51 个 assay、检测体系与效价标尺互不可比。可迁移性的根本解法不是更好的模型，而是**同一批分子跨多个 assay 的对齐数据**（可估计 assay 间变换并可跨 assay 训练）。

**T1 内容（下轮执行，纯计算/检索）**：
1. 在 master 内统计 assay 两两共享分子数矩阵；识别 ≥15 个共享分子的 assay 对（若存在）；
2. 对每个候选 assay 对：用共享分子拟合 assay 间变换（线性/offset），报告变换的 R² 与残差；
3. 若存在 ≥2 个可对齐 assay 且变换稳定 → 构建"assay 归一化训练集 v1"，重跑 E1–E4 分层验证；
4. 若公开数据不存在可对齐 assay 对 → 如实记录，FASN 的定量主轴价值降为"canonical assay 内排序 + 方法学"（触发 A3 降级评估点）。

**T1 通过标准（预冻结）**：归一化训练集上，E1/E2 分层 Spearman ≥ 0.5 且 pooled R² ≥ cal_mean 基线 +0.05，10 seeds 稳定。

**T1 失败动作**：FASN 轴降级为方法学/数据审计线；主发现权重完全移至 Moracin N 轴；不训练 GNN、不扩天然产物预测。

## 四、资源分配确认

按本轮指令 70–80% Moracin N / 20–30% FASN：Moracin N 未到货导致湿验 blocked，故本轮 FASN 占比临时上调（符合"湿实验条件暂时无法启动时 FASN 可增加投入"条款）；物料到货后立即回切 70–80% 湿验优先。
