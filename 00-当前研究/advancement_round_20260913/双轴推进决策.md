# 双轴推进决策

**日期：2026-09-13**

## 一、Track A（FASN）本轮终点判定：**A2**

> **只在 assay-near / 化学域内迁移；FASN 维持 CONDITIONAL GO，适用范围收窄。**

依据（全部本轮实跑，见 `FASN_transferability_report.md`）：

- 失败分解：化学域失配（主：OOD rho 0.08–0.52）× assay 效价标尺失配（次：E1_ADin 偏移 −0.663）；
- 化学域内排序可迁移（E1_ADin rho **0.880**，未用外部标签）；小标签校准后跨 assay 排序 rho **0.69** 稳定（10 seeds）；
- 绝对效价迁移**不成立**（cal_mean 基线 0.272 ≥ 一切模型 ≤0.267）；
- 桥接数据 v2 确认天然产物直接生化点仍 ≈0–5 个且非人源酶 → NP 筛选资格继续冻结；
- GNN 继续关闭；
- 下一道门 = Gate T1（多 assay 对齐数据集组装），通过/失败分别对应主轴继续或降级。

**未走 A1**（无"明显改善"的全局证据）、**未走 A3**（存在稳定可复现的条件性迁移信号，不足以降级）。

## 二、Track B（Moracin N）本轮终点判定：**B-pending（GO 维持，第一份数据未产生）**

- 物料未到货（无 COA/批号/到货记录）→ 按指令转为**实验启动包冻结**，M0/B0/毒窗/Gate1 全部 not_executed，不伪造数据；
- Track B 的资格判定维持资格验证轮的 **GO**（进入验证的资格已冻结：Gate 编号 vFinal + 双轴判读框架 + 干扰前置全部就绪）；
- 本轮不产生 B1/B2/B3 结论——那需要真实 Gate 1 数据。

## 三、组合执行

| 项 | 决定 |
|---|---|
| 双轴是否继续 | **是**（FASN CONDITIONAL GO 收窄版 + Moracin N GO 待执行） |
| 资源分配 | 本轮因湿验 blocked 临时 70/30 倒置（FASN 加投，符合指令的例外条款）；物料到货后立即回切 **70–80% Moracin N 湿验** |
| 风险隔离 | 两轴失败互不连坐（维持） |
| 禁止事项 | 全部继续有效：无门控 GNN、NP54 排行榜、THRβ 新 docking、MM/PBSA、长 MD、TOPSIS、人工综合分 |

## 四、本轮净产出

1. FASN 从"单 assay 局部模型"向"跨 assay 可迁移模型"迈出了**被量化的一步**：明确知道可迁移的是排序（化学域内 rho 0.88 / 校准后 0.69），不可迁移的是效价水平与 OOD；
2. 方法学三处口径修正（Y-scrambling / chemical-series confinement / NRF2 证据等级）全局生效；
3. Moracin N 实验启动包 100% 冻结——到货即执行，无需再讨论设计。
