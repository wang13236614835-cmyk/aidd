# 最小实验验证方案（v2，仅设计，不冒充已执行）

## Gate 0：所有首轮对象共用
对象：scoparone、alisol B、hyperoside、puerarin、isorhamnetin、formononetin。

1. 人工核对 CID/InChIKey、供应商结构图、CoA、批号、HPLC/LC-MS纯度、母体/盐型和有效期。
2. DMSO储液稳定性、培养基稀释后0/1/4/24 h浑浊、离心上清、UV-Vis 200–800 nm；必要时DLS。
3. 无细胞报告/检测试剂干扰：荧光素酶、MTT/CCK-8/ATP/LDH；有背景偏差时改用正交读出。
4. 用ATP/Calcein-AM/细胞计数+LDH排除“细胞死了所以脂滴少”的假阳性。
5. 初始浓度0.03、0.1、0.3、1、3、10 μM；上扩必须满足无沉淀、无读出干扰和非毒性。

## Gate 1：同板疾病表型
- 模型：PA/OA脂毒性肝细胞（AML12或负责人认可的人源肝细胞）。
- 对照：正常+车辆、脂毒性+车辆、阳性药物（实验室认可FXR/代谢对照）、DMSO同浓度；每个候选至少3次独立生物学重复。
- 主终点：细胞TG和油红O/等价脂质定量；辅以细胞活性、LDH、炎症/脂合成/脂氧化指标。
- 判定：在无毒/无干扰窗口中相对脂毒性组有可重复、预注册效应；仅单一脂滴下降不能称完整抗MASH。

## Gate 2A：FXR候选分流
对象：Gate 1阳性的 isorhamnetin、formononetin，必要时 hyperoside/puerarin。
- FXR敲低或拮抗条件；SHP/BSEP/FGF19等靶基因；FXR报告基因只作为功能之一。
- 直接结合与功能分开：SPR/MST/ITC/CETSA之一必须配结构/非特异性对照；不把ITC/MD单独写成完整target engagement。
- formononetin：并行SIRT1抑制/敲低，问FXR与SIRT1–FAO是否同一因果链。
- isorhamnetin：若报告基因受干扰，改用TG/qPCR/蛋白/结合正交读出。

## Gate 2B：肝细胞/HSC/炎症分流
对象：scoparone、alisol B、hyperoside、ursolic acid。
- 肝细胞与LX2/HSC分别评价；不把一个细胞类型的读出外推完整MASH。
- alisol B：CD36/RARα–HNF4α–PPARγ因果；严格区分母体、AB23A和acetate。
- scoparone：TLR4/NF-κB、自噬流和巨噬细胞炎症；不把miRNA–mRNA 3′UTR写成蛋白结合。
- hyperoside：Flot2/TLR4/NLRP3、FXR/ACLY均需正交验证。
- ursolic acid：SPP1/ITGB1/CD44/ERK分泌型轴；先解决低溶解度/车辆。

## Gate 2C：铁死亡分流
对象：moracin N和puerarin（仅在Gate 1相关表型阳性后）。
- erastin/RSL3刺激；C11-BODIPY脂质过氧化、可交换铁、GSH/GPX4、细胞活性。
- ferrostatin-1/deferoxamine救援；NAC作为一般抗氧化对照。
- 只有铁依赖脂质过氧化和特异性救援同时成立，才支持铁死亡机制。

## Gate 3：动物前门
只有 Gate 0–2 均可解释且有初步暴露/可达浓度时，才讨论治疗性MASH模型、PK、组织学、转录组和组合用药。动物参数需伦理审批和实验负责人确定，不由本文件自动启动。

## 决策树
- 身份/可测性失败 → 停止解释，换批次或换读出。
- 表型失败 → 降级该候选，不用docking/AI补救。
- 表型有效、机制干预无效 → 保留表型，撤销该机制。
- 机制和表型有效、暴露不可达 → 进入递送/结构优化，不称候选药物。
- 六对象均失败或不可解释 → 暂无合格候选。
