# 最小湿实验方案 v3（第五轮，2026-09-12）

**原则**：本科大创真实可完成；每关都有预注册判定与淘汰条款；失败是有效结果，不追加 docking/换阈值救阳。本文件为设计方案，非已执行记录。预算量级：全部四关在 1–2 万元内可完成（细胞系 1–2 种、96 孔板体系、无动物）。

## Gate 0：共同第一关（所有分子进任何细胞板之前）

| 项 | 做法 | 判定 |
|---|---|---|
| 标准品身份 | 到货核对 CAS/InChIKey/纯度（HPLC/MS 报告单扫描存档）；formononetin/biochanin A/moracin N/isorhamnetin/3'-MOD 五者分开登记 | 无报告单 → 该分子不进板 |
| 溶解性 | DMSO 储液 10/20/50 mM 三档目视+24 h 浊度；培养基稀释 0.03–30 μM 即时/24 h 浊度 | 出现不可逆沉淀的浓度带标记为不可解释区 |
| 无细胞光谱 | 200–800 nm 吸收扫描（各浓度）；若用荧光读出则做 Ex/Em 扫描 | 与检测通道重叠的浓度不得用于该读出 |
| reporter 干扰 | 底物+缓冲液+化合物梯度（无细胞、无受体） | 相对 DMSO 偏差 >15% 的浓度带禁用于报告基因解释 |
| 活性读出干扰 | ATP/Calcein-AM/LDH 三联（不用单一 MTT）；化合物+试剂无细胞对照 | 还原/吸光背景扣除或换法 |
| 聚集 | 浊度 + 离心（15 min, 14k rpm）前后上清对比；可选 DLS | 离心后效应消失 → 判聚集假阳性 |

isorhamnetin 的 Gate 0 是晋级门（B−→B）；其余分子为常规质控。

## Gate 1：MASH-like 肝细胞表型（moracin N 主战场；formononetin/isorhamnetin 同板）

- 模型：HepG2 或 AML12，PA/OA（0.4–0.5 mM PA+干预 16–24 h；预实验定毒窗）。
- 读出（最小集）：油红 O/BODIPY 脂滴、TG 定量、细胞活性（ATP/Calcein）、LDH。
- 分组：模型对照、vehicle、阳性对照（可选：ferrostatin-1 作为铁死亡参照）、化合物 4–6 点浓度（Gate 0 允许带内）。
- 判定：无毒窗口内 TG/脂滴显著且可重复改善（≥3 独立重复，ANOVA+多重校正）→ 过关；单一脂滴下降不称"抗 MASH"。

## Gate 2：机制限定指标（只测四个：Nrf2、GPX4、SLC7A11、ACSL4）

- 平台：qPCR（最省）+ 优选 1–2 个 WB（Nrf2 核转位或 GPX4）。
- 铁死亡特异性证据：C11-BODIPY 脂质过氧化 + GSH + （可选）Fe²⁺ 探针；ferrostatin-1（1–5 μM）救援作为体系阳性。
- 禁止铺全通路大摊子；不做磷酸化蛋白组/转录组。

## Gate 3：因果裁决（最便宜的决定性实验）

### moracin N（H2 裁决）

- 设计：PA/OA + moracin N ± **ML385（Nrf2 抑制剂，文献先例 PMID 40972263）**；有条件加 Nrf2 siRNA 敲低双保险。
- 预注册判定：表型改善被 ML385 消除（改善幅度残留 <30%）→ Nrf2 必要性成立，H2 升级；不受影响 → H2 淘汰（写入结题与论文为机制重定位未获支持）。
- 铁死亡特异性：ferrostatin-1 救援方向一致才可写"铁死亡依赖"。

### moracin N（H1 裁决，独立于 H2）

- 平行三读出 reporter：TRβ1 与 TRα1 平行转染（TRE-luc，HepG2 或 HEK293，同板两亚型平行孔，T3 标准化）。
- 三分支分开报告不互换：① 单药激动；② T3 共孵拮抗；③ T3 亚饱和敏化（Ariyani 2018 框架）。
- 对照：T3、resmetirom（阳性）；空载体板（reporter 干扰）；constitutive Renilla（双荧光校正）。
- 判定：单药 ≥T3 最大效应 10% 且剂量一致 3/3 显著记激动阳性；敏化 ≥130% 记增强；拮抗 ≥30% 抑制且浓度依赖记抑制。**TRβ 与 TRα 全阴性 → H1 淘汰（不影响 H2）**。两亚型均阳性时也不得称"亚型选择性"，只报比值。

### formononetin（FXR 依赖性裁决——本项目核心增量）

- 设计：PA/OA 表型板 + FXR 阻断（Gly-MCA 肠道选择性或 z-guggulsterone 泛拮抗，二选一按可得性；有条件加 FXR siRNA）；同批跑 FXR Ostβ-luc reporter（biochanin A 当批阳性 QC，复现 CJNM 2024 方向）。
- 预注册判定：阻断后表型改善残留 <30% → "FXR 是主要药效介质"成立；残留 ≥70% → 该假说不成立，改写为 SIRT1/PGC-1α/PPARα 为主（表型锚点保留）。
- 增量问题同时记录：FXR 阻断是否改变 SIRT1/PGC-1α/PPARα 读出（qPCR 三基因即可），回答两线因果层级。

### isorhamnetin（条件分支）

- 仅当 Gate 0 全通过：并入上述同板，做 FXR 阻断残留 +（可选）FXR reporter——作为"疾病证据外部参照"，不单独消耗一轮。
- Gate 0 失败 → 直接降 D，本方案内无补救分支。

### 3'-methoxydaidzein（暂缓对象的条件分支）

- 仅在导师明确要求且完成 NaV 风险评估后：FXR reporter + TRβ/TRα reporter 各一板（结构假说分流），**须带 NaV 不表达对照系（HEK293 无内源 NaV 即为天然对照）并在讨论中披露 NaV 离靶**。
- 默认不执行；经费未解锁。

## 对照与统计纪律

- 每板：vehicle、模型、阳性、（机制板加阻断剂单药对照）；≥3 独立重复；预注册主终点在跑板前写入本文件附录（补录版本号）。
- 阴性结果按预注册规则报告，解释权归实验负责人；禁止跑后调阈值。

## 预算与可行性量级（本科大创）

| 项 | 量级 |
|---|---|
| 细胞系 | 1–2 种（HepG2 或 AML12/HEK293）；无动物 |
| 试剂 | 药品标准品 5 种（小包装）、PA/OA、油红 O/BODIPY、TG/ATP/LDH 试剂盒、C11-BODIPY、ferrostatin-1、ML385、Gly-MCA 或 z-guggulsterone、荧光素酶双报告系统 |
| 质粒 | TRE-luc + TRβ1/TRα1 表达质粒（可商用/共享）+ Renilla |

## 放弃条款汇总（与榜单 v3 一致）

- moracin N：H2 与 H1 双阴性 → X；仅 H2 阴性 → H2 淘汰、H1 独立继续（或反之）。
- formononetin：FXR 阻断残留 ≥70% → 撤销主要介质结论（锚点保留）。
- isorhamnetin：Gate 0 失败 → D。
- 3'-methoxydaidzein：任何 FXR/TR 阴性或动物阶段 NaV 未解决 → X。
