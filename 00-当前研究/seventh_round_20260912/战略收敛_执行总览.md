# 战略收敛轮执行总览

**日期：2026-09-12**

## 结论先行

本轮冻结一个主方向，不再并列保留四条主线：

- **主方向：MASH 相关肝细胞脂毒性中的 Nrf2 依赖性抗脂质过氧化/铁死亡机制。**
- **主机制定位：KEAP1–NRF2–GPX4/SLC7A11 防线；KEAP1 是上游调节背景，不把 Moracin N 直接结合 KEAP1 写成已证实事实。**
- **主计算方法：证据驱动的机制重定位 + 化学信息学身份/干扰/适用域审计 + 结构解释；不以 docking、GNN 或无标签预测作为候选排序器。**
- **主候选：Moracin N。** 定位为“优先机制重定位候选”，不是已验证药物。
- **第二候选：Isorhamnetin。** 仅在 Moracin N 材料失败且通过三项无细胞干扰预筛后启用；不是同等优先级。
- **疾病证据锚点：Formononetin / biochanin A 的已发表 FXR 活性和 formononetin 的疾病机制证据。** 仅作为比较轴、体系阳性/机制锚点，不占主发现位。
- **Plan B：FASN/de novo lipogenesis。** 先冻结带 assay provenance 的 FASN 数据，RF/XGBoost 基线通过严格外推验证后，再做天然产物扩库和直接酶抑制实验。

## 前四轮真正排除了什么

1. **排除 docking 主导候选排序。** 旧 N331S TRβ 区分门控 ROC-AUC 0.346；WT TRβ 门控 ROC-AUC 0.472，95% CI 0.341–0.607，分层方向不一致。姿态恢复通过只说明协议可近似重现晶体姿态，不能说明活性、激动方向或亚型选择性。
2. **排除 Moracin N = TRβ 第一名的表述。** Moracin N×TRβ 在指定检索边界内没有直接功能/结合证据，THRβ 口袋 docking 只能保留结构假说。
3. **排除 Formononetin = 新发现 FXR 激动剂。** CJNM 2024 已报告 formononetin 的 FXR SPR/报告基因活性；biochanin A 也已被直接验证。
4. **排除 3'-methoxydaidzein 为低风险创新候选。** 已有 NaV1.7/1.8/1.3 亚微摩尔级本体功能活性，并有 NaV1.5 心脏通道风险信号。
5. **排除把旧 FXR/GNN 或多靶 QSAR 泛化到天然产物。** 旧 FXR GNN 随机切分 R² 约 0.790，但 scaffold split R² 为 −0.610；新 FXR RF 虽有同 assay 内部性能，54/54 天然产物仍低于拒判域。
6. **排除把 FASN/ACC 历史结果直接升级为候选依据。** FASN 旧数据存在 assay/document/construct 被压缩问题，旧 cluster 结果因划分错误不能直接采信；ACC 只有部分历史结构和数据资产，没有当前候选释放链。

## 为什么主线不是“数据最多”的 FASN

FASN 的确是本轮最强的计算备选：最新 ChEMBL 有 1,139 个去重分子、1,652 条精确 IC50/Ki/Kd 记录；denifanstat 2b 也提供了较强临床转化信号。但当前库没有经过 FASN 专门设计，历史 FASN assay provenance 不完整，结构门控种子敏感，且现有 54 个天然产物没有直接 FASN 机制验证。直接转向 FASN 会先增加数据清洗、扩库、酶实验和预算，不会比 Moracin N 的最小因果实验更快得到可靠答案。

相反，Moracin N 已有神经元/脑缺血层面的抗铁死亡、Nrf2/ML385 因果证据；MASH 侧有独立的肝细胞铁死亡与 Nrf2 防线证据；两者之间的“肝细胞脂毒性连接”可以用一套已预注册的最小实验裁决。主线奖励的是**未来最可能在两年内获得真实、可证伪结果**，而不是历史计算量。

## 未来 1–2 年执行顺序

### 阶段 0：干实验冻结（现在—1 周）

- 不再扩展 docking 排名。
- 固化本轮路线、候选角色、失败条件和数据版本。
- 申请 Moracin N、ML385、Fer-1 试用/报价；复核 COA、立体/异构体和溶剂稳定性。
- 只保留 54 库身份和天然来源审计，不把库表来源标签升级为实验分离来源。

### 阶段 1：Moracin N 最小验证（导师批准后 1–3 个月）

- HepG2 + PA:OA=1:2，总 1 mM、BSA 偶联、24 h；只称“肝细胞脂质蓄积+脂毒性氧化应激模型”，不称完整 MASH。
- Gate 0：无细胞浊度、吸光/荧光和探针干扰。
- Gate 1：活力、细胞 TG、油红 O；7 点 0/0.1/0.3/1/3/10/30 μM，DMSO 恒定 0.1%。
- Gate 2：GSH、ROS/C11-BODIPY、GPX4/SLC7A11/ACSL4，Fer-1 作为铁死亡系统参照。
- Gate 3：模型、Moracin N、ML385、Moracin N+ML385 四组；预注册削减率 ≥70% 支持 Nrf2 依赖，<30% 不支持“主要介质”主张；化合物失败与机制失败分开报告。

### 阶段 2：条件扩展（仅 Gate 1–3 通过后）

- 扩展到第二细胞背景或 L02/AML12，避免单一 HepG2 外推。
- 做 Nrf2 核转位/ARE 或 siRNA 作为 ML385 的正交验证。
- 只在条件具备时加入 GPX4 蛋白定量、C11-BODIPY 和通路时间序列。
- 仍不直接宣称口服暴露、完整 MASH、动物疗效或直接 KEAP1 结合。

## 全局决策规则

- Gate 1 无毒窗口内无表型改善：Moracin N 在本模型出局，主候选不再强行维护。
- Gate 2 无至少两个机制读数改善：H2 机制主张暂停，候选结果与机制结果分开。
- Gate 3 ML385 削减 <30%：撤销“Nrf2 为主要介质”，保留“本模型表型候选”或停止。
- H1 TRβ reporter 若要做，只能使用现成平台、零新计算、零额外主线预算；不得用 docking 翻案。
- 主线与 Plan B 均不得在没有原始数据、适用域和外部验证时训练“漂亮的 GNN”。

## 本轮的科学判断

主线不是“证明 Moracin N 已经抗 MASH”，而是用最小因果实验判断一个有直接神经元层机制证据的天然产物能否被重定位到 MASH 相关肝细胞脂毒性。阳性、阴性和材料不可行均有预先定义的科学信息价值。
