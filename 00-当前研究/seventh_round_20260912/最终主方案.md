# 最终主方案

## 冻结版本

**主方向：MASH相关肝细胞脂毒性中的 Nrf2 依赖性抗脂质过氧化/铁死亡机制。**

**主靶点/机制：KEAP1–NRF2–GPX4/SLC7A11 轴；以Nrf2必要性为核心因果问题，KEAP1不作直接结合已证实主张。**

**主候选：Moracin N。** 角色为优先机制重定位候选，尚未验证。

**第二候选：Isorhamnetin。** 仅在Moracin N材料不可行或主线需要备用时启用，并先通过无细胞干扰门；不是并列主候选。

**机制锚点：Formononetin。** 用于疾病证据/FXR依赖性比较，不作为Nrf2主线候选；biochanin A仅作FXR体系QC/阳性参照。

## 主计算方法

1. 证据驱动机制重定位：连接Moracin N已发表神经元Nrf2/ferroptosis证据与MASH肝细胞铁死亡独立证据。
2. 化学信息学审计：身份、来源、供应链、溶解度、聚集、荧光/氧化还原和探针干扰。
3. 结构解释：历史docking只回答口袋占据/姿态假说，不进入候选排序。
4. 预注册最小因果实验：Gate 0→Gate 1→Gate 2→Gate 3。
5. 结果不使用综合分；以预冻结阈值、证据层级、状态三分和明确Go/No-Go报告。

## 最小实验

### Gate 0

无细胞浊度、光谱和探针干扰；确认Moracin N储备液、DMSO 0.1%恒定和细胞可测窗口。

### Gate 1

HepG2 + PA:OA=1:2，总1 mM，BSA偶联24 h；Moracin N 0.1/0.3/1/3/10/30 μM；CCK-8、TG主端点、油红O支持读出。模型有效性：模型/空白TG≥1.8且活力≥70%。

### Gate 2

GSH、ROS/C11-BODIPY、GPX4、SLC7A11、ACSL4；至少两个机制读数改善；Fer-1作铁死亡系统参照。

### Gate 3

四组：模型、模型+Moracin N、模型+ML385、模型+Moracin N+ML385。削减率≥70%支持Nrf2依赖；<30%撤销“Nrf2主要介质”；中间区间重复/正交验证，不事后改阈值。

## 主张边界

- 允许：在HepG2 PA/OA脂毒性模型中支持/不支持Nrf2相关抗脂质过氧化机制。
- 禁止：已发现新药、已证实抗MASH药物、完整MASH治疗、直接KEAP1配体、口服有效、长期安全、首次发现。

## 预期产出

- 若Gate 1–3阳性：形成“机制重定位+最小因果验证”论文/结题故事；后续扩展第二细胞背景和正交Nrf2干预。
- 若Gate 1阳性、Gate 3阴性：只保留表型候选，撤销Nrf2主要介质主张。
- 若Gate 1阴性或材料不可行：如实报告本模型未获支持/材料不可行，触发Plan B或停线。
- 全部结果包括原始点、重复、失败和未完成项，不把阴性擦除。

## 预算和时间

优先使用第六轮已冻结采购包和分期采购：Gate1先行，Gate2/3过门后再下单。核心目标是在导师批准后1–3个月得到Gate1–3初裁，不启动动物、不启动大规模MD、不继续扩大docking。
