# KEAP1–NRF2–GPX4 / ferroptosis 路线深度审计

## 一、需要先改正的机制表述

本路线的可检验命题是：

> **Moracin N 是否能在 MASH 相关肝细胞脂毒性模型中改善脂质过氧化/铁死亡表型，并且该保护效应是否依赖 Nrf2 轴。**

KEAP1 是 Nrf2 的上游调节背景；GPX4、SLC7A11、GSH、ACSL4 和脂质过氧化是机制读出。除非获得直接结合/竞争或结构生物学证据，不把 Moracin N 写成“直接 KEAP1 配体”，也不把 GPX4 写成已确认直接靶点。

## 二、Moracin N 侧直接证据

- PMID 34281775，Phytomedicine 2021：HT22 海马神经元 erastin 模型中，Moracin N 抑制 GSH耗竭、GPx4失活、ROS和铁积累，抗铁死亡 EC50<0.50 μM（摘要层级）。
- PMID 40972263，Phytomedicine 2025：脑缺血再灌注/原代神经元模型中，Moracin N 与 Keap1/Nrf2 激活、GSH 合成和 FTH1/ACSL4 变化相关；ML385 可阻断保护效应。
- 脑室内给药、神经元细胞证据不能外推为口服肝暴露或 MASH 疗效；摘要未提供本项目需要的全部剂量和浓度细节。
- 本轮指定检索边界内未发现 Moracin N×MASH/NAFLD/肝细胞直接研究，也未发现 Moracin N×THRβ/FXR直接功能证据。

## 三、MASH 侧独立证据

- MASH/NAFLD 中肝细胞铁死亡、脂质过氧化和 GPX4/GSH 防线已有细胞/动物研究；项目第五轮已记录 RSL3、liproxstatin-1、去铁胺、NRF2防线等独立证据。
- PMID 39922149（2025）报告 hinokitiol 在小鼠 MASH 中靶向肝 Nrf2、抑制肝细胞铁死亡；这是疾病链可行性先例，不是 Moracin N 证据。
- PMID 40803417（2025）报告 baicalein 通过 Nrf2 调节巨噬细胞铁死亡减轻 MASH；同样是独立天然产物先例。
- 2026 PubMed 检索继续出现 Nrf2/ferroptosis 与 MASLD/MASH 的关联研究，说明该领域有热度；因此本项目新意不能写成“没人研究过铁死亡”，而应写成“Moracin N 的跨细胞类型机制重定位与 Nrf2 必要性验证”。

## 四、风险审计

1. **Nrf2长期激活风险。** Nrf2在肿瘤和耐药环境中的持续激活可能具有双刃剑效应；本项目只能回答短时肝细胞模型中的必要性，不能推断长期安全性。
2. **抗氧化剂读数假阳性。** Moracin N及多酚类可能直接淬灭 DCFH-DA、改变荧光或形成胶体；Gate 0 和多读数交叉验证是硬门。
3. **细胞类型依赖。** Moracin N在神经元的保护不能保证在 HepG2、AML12 或 L02 中同方向；A549/PC9等肿瘤细胞已有相反的ROS/凋亡背景提示。
4. **ferroptosis 与一般抗氧化不能混同。** Fer-1系统对照、C11-BODIPY/GPX4/ACSL4/GSH组合和活力窗口共同决定解释强度。
5. **模型外推边界。** PA/OA HepG2只模拟脂质蓄积和脂毒性氧化应激，不模拟炎症小叶、纤维化、免疫和全身代谢。

## 五、实验裁决

### Gate 0：无细胞可测性

浊度、吸光/荧光、探针淬灭、溶剂和储备液稳定性；任一关键干扰无法排除，状态写“材料/检测不可行”，不写生物学阴性。

### Gate 1：表型

HepG2 + PA:OA=1:2，总1 mM、BSA偶联24 h；Moracin N 0.1–30 μM、DMSO恒定0.1%。主端点为蛋白归一化TG；活力与油红O为支持读出。预冻结：无毒窗口内TG降幅≥25%才进入下一门；无浓度达到15%或10 μM以下活力不合格则本模型淘汰。

### Gate 2：机制方向

GSH、ROS/C11-BODIPY、GPX4/SLC7A11/ACSL4至少两个读数改善，并由 Fer-1提供系统级铁死亡参照。不得用单一 DCFH 读数作机制证据。

### Gate 3：因果

模型、Moracin N、ML385、Moracin N+ML385四组；以TG及预注册机制读数计算 Moracin N 保护效应的削减率：≥70%支持“Nrf2依赖性主要介质”；<30%撤销主要介质表述；中间区间进入重复/正交验证，不改判据追求阳性。

## 六、AIDD在本路线中的真实作用

- 不是训练“NRF2活性GNN”。NRF2/GPX4是通路节点/读出，当前没有足够统一的 direct binding/activity 数据支撑单一GNN。
- AIDD贡献是：从可追溯天然产物库提出重定位连接；整合 Moracin N 已发表机制、MASH 独立病理链、身份/干扰/适用域审计；用结构结果仅作解释；将实验设计为最小、预注册、可证伪的因果门控。
- 只有当未来获得同一 KEAP1 PPI assay 的可靠数据集时，才评估 KEAP1 小分子模型；不能把所有 NRF2 激活文献混为 KEAP1结合标签。

## 七、成功和失败都如何解释

- Gate 1阴性：Moracin N在本肝细胞模型中未获支持，不等于其神经元机制错误。
- Gate 3阴性：表型可能存在，但“Nrf2为主要介质”不成立；可转为未定机制候选或停止。
- 双机制竞争中H1/TRβ reporter也阴性：Moracin N整体降级，不再用 docking复活。
- Gate 1–3阳性：仍只能写“在本模型中支持 Nrf2 依赖性抗脂质过氧化/铁死亡保护”，不能写已治疗完整 MASH或已成为药物。
