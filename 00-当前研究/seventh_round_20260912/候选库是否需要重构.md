# 候选库是否需要重构

## 结论

**需要重构，但不是现在立即扩充 54 个分子。**

先完成主线 Moracin N 的 Gate 0–3；只有在主线通过、材料失败需要备用、或切换到 FASN Plan B 时，才按新靶点/机制重建候选库。当前54库冻结、保留历史，不直接回池凑数。

## 54个库可以保留什么

- 54个结构身份、SMILES、CID、理化属性和三靶 docking 原始输出作为历史审计资产。
- Moracin N作为主机制重定位对象。
- Isorhamnetin作为同库书面备用，但必须先做聚集、光谱和氧化还原三项无细胞干扰门。
- Formononetin作为疾病/FXR机制锚点；biochanin A作为FXR板级QC/阳性参照。
- 3'-methoxydaidzein继续暂缓，不因旧dock或“空白”复活。

## 54个库存在的结构性偏倚

- 过滤后54个分子来自有限药材来源：茵陈9、山楂11、泽泻7、决明子6、葛根8、垂盆草1、叶下珠3、桑叶6、虎杖3。
- 这是“过滤后的传统药材成分池”，不是覆盖天然产物化学空间的代表性库。
- 黄酮/异黄酮、多酚、苷类和三萜比例受来源与MW/性质过滤影响；不应把这个库的阴性当作天然产物总体阴性。
- 来源标签必须分为库表/database-only、PubChem身份、文献实验分离、人工复核；不能直接称“54个均为药材直接分离成分”。

## 如果主线A继续

不需要立即扩库。优先级是：

1. Moracin N身份/COA/供应链闭合；
2. Gate 0检测干扰；
3. HepG2 PA/OA表型和Nrf2因果；
4. 结果阳性后再扩充同一机制的天然产物参照，例如已有肝/铁死亡/Nrf2证据且可采购的化合物；扩充时先预注册纳入标准。

Isorhamnetin不自动替代Moracin N：它有NASH/FXR相关疾病证据，但多酚聚集、荧光和氧化还原干扰需要先排除。

## 如果切换到FASN Plan B

需重构为“FASN专用库”，不直接把54个旧分子当作充分筛选库：

- 数据侧：重新冻结FASN assay-specific训练集，并保留assay/document/construct。
- 参照侧：加入phloretin、EGCG、kaempferol、quercetin、asiatic acid等有直接FASN抑制文献的参照；它们需要独立确认结构、来源、纯度和疾病层级。
- 候选侧：从54个库中提取可采购、身份和干扰门合格者，再加入明确来源可追溯的民族药/中药成分；不按dock分数补入。
- 负对照侧：加入相同化学型、同一assay已测弱/阴性或机制不相关的对照，避免只有多酚阳性。
- 实验侧：直接FASN酶抑制和肝细胞脂质读出分开；酶抑制阳性不能自动等于细胞/疾病阳性。

## 是否应加入更多民族药/中药成分

可以，但须满足：

- 药材部位和实验分离/标准品来源可追溯；
- PubChem/CID/InChIKey/规范SMILES闭合；
- 结构立体化学和盐/糖苷状态明确；
- 有明确纳入问题（Nrf2/ferroptosis或FASN），而不是扩大数量；
- 纳入前完成PAINS/聚集/荧光/氧化还原/溶解度审计；
- 预先定义候选启用条件、阴性对照和停止线。

## 重构停止线

- 不因“54个太少”就先扩至数百个。
- 不因模型需要更多样本而用无标签天然产物伪造训练标签。
- 不将药材存在、数据库登记、提取物活性和纯化合物直接结合混为一类证据。
- 不扩库来绕过主线实验阴性；阴性应保留为结果。
