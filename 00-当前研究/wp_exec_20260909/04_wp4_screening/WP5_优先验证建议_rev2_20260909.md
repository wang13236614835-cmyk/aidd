# WP5 优先验证建议(rev2,2026-09-09;回应技术审查 P1 退回项)

**取代** `WP5_优先验证建议_初步_20260909.md`(保留存档不删)。性质:待复核建议名单;湿实验仅制定方案。分级命名不越级:计算命中物→实验确认命中物→先导→候选。

## 一、主研究问题(采纳审查建议表述)

**现有天然产物计算命中物是否具有可重复的 TRβ 调节活性,以及这种活性是否表现出相对 TRα 的选择性,并值得进入抗 MASH 相关细胞验证?**——这是研究问题,不是结论。

## 二、实验设计(修订版:补齐选择性与干扰设计)

| 要素 | 设计(修订点加粗) |
|---|---|
| 读出系统 | TRβ1 与 **TRα1 平行**转染报告基因(TRE-luc/DR4-luc;HepG2 或 HEK293),**同一细胞板内两亚型平行孔**,选择性 = TRβ 途径活性 / TRα 途径活性的比值(每板以 T3 标准化) |
| **三读出方向**(P0 矩阵教训) | ①单药激动;②T3 共孵拮抗;③**T3 亚饱和浓度下的转录增强(敏化模式,Ariyani 2018 框架)**——三条分开报告,互不换算 |
| 阳性对照 | T3(内源性)、resmetirom(获批 THR-β 激动,亚型选择性参照) |
| **拮抗对照(替换 GS)** | **NH-3**(首选:Grover 2007 JPET,PMID 17440037,IC50≈55 nM,GC-1 衍生 pan-TR 拮抗;注意 Shah 2008/Walter 2021 记载其作用复杂,结果解释须限定)与 **1-850**(备选:CAS 251310-57-3,Sigma 609315,竞争性阻断 T3-TRα/TRβ,IC50≈1.5 μM;Manka 2024 Liver Int 肝星状细胞先例)。**两者均非亚型选择性拮抗剂**,拮抗模式结论限"TR 途径抑制"不作亚型归因 |
| **系统干扰对照** | 空载体(无 TR 表达质粒)平行板:排除化合物直接抑制荧光素酶/影响细胞活力造成的假阳性;荧光素酶对照质粒(constitutive Renilla)共转染双荧光素酶校正 |
| **受体依赖性裁决** | TRβ siRNA 敲低(或显性负 TRβ):活性被敲低消除→TR 依赖;不受影响→非 TR 途径(转录/毒性间接效应) |
| 剂量与毒性 | 浓度反应至少 6 点,范围由**预实验确定**(溶解度上限与 CellTiter 毒性线,<70% 存活浓度剔除);**独立重复 ≥3 次**,预注册主终点=最大激动/增强倍数(相对同板 T3 最大效应的百分比)与拟合 EC50,次级=T3 拮抗 IC50 |
| 判定规则(预注册) | 单药激动:T3 最大效应≥10% 且剂量一致、重复 3/3 显著(ANOVA+多重校正)记阳性;敏化:T3 单独为 100%,共孵≥130% 记增强;拮抗:T3 效应抑制≥30% 且浓度依赖记抑制。**阴性结果的解释权归实验负责人** |
| FXR 交叉(保留) | 同批 FXR Ostβ-luc:formononetin/biochanin A 应复现 CJNM 2024 阳性(体系当批质量控制)、daidzein 复现 Hiebl 2018 单条件阴性;**FXR 交叉只回答 FXR 问题,不回答 TRα/TRβ 选择性** |
| 疾病表型衔接(后置) | 上述任一阳性后,再设计 MASH 相关细胞表型(游离脂肪酸负荷 HepG2/AML12 脂变模型)与靶基因 mRNA(DIO1/MeT2 类 TRβ 靶点),**功能、结合、表型三类终点分别报告,不互相替代** |

## 三、优先对象(rev2:daidzein 重定位;不锁死名额)

| 优先级 | 分子 | 定位(rev2) | 依据与限定 | 下一项最有价值测试 |
|---|---|---|---|---|
| 1 | moracin N | 探索对象 | 计算重复性支持(全库 4 种子+双管线第 1;**2026-09-09 区分能力门控失败后,该排名为探索性技术排序,不构成活性先验**);任何 TR 模式无文献(以 P0 矩阵为限);**未证明 TRβ 功能或选择性** | TRβ/TRα 平行三读出 |
| 2 | formononetin | THRB 交叉活性研究对象 | FXR 已验证(CJNM,不能再作新发现卖点);THRB 排名中段(第 10 左右,正构占据假设弱于 moracin N;排名同样属探索性技术排序);问题聚焦"已验证 FXR 激动剂是否兼有 TR 调节" | 同上 |
| 3 | daidzein | **既往 TR 研究对象/条件对照**(rev1"THRB 空白验证对象"撤回) | Takeuchi 2009(CHO,标准激动/拮抗,阴性)+Ariyani 2018(CV-1,T3 协同增强,阳性)——**优先级重审后仍列队的理由**:本项目体系可裁决两文献条件差异(细胞系/读出框架),作为方法学对照物价值高于新对象价值 | 与 1、2 同批;重点做 T3 亚饱和敏化模式(复现 Ariyani)与本项目细胞系的适配 |

**计算证据地位声明(2026-09-09 门控后)**:TRβ 区分能力门控(预注册)失败——Vina 分数在 ChEMBL TRβ 活性/floor 阴性集上无区分能力(AUC 0.346,MW 残差 0.647);全库排名降级为探索性技术排序。上表选择依据中"计算排名"的权重相应下调,三对象列队的核心理由转为:①对象可得与成本,②文献覆盖的互补性(空白/交叉/条件对照),③计算重复性(技术层)。实验裁决地位上升。
| 储备 | biochanin A、3'-methoxydaidzein、moracin M、capillarisin 等 | 按统一规则补充比较;**不强制锁死三名**(审查要求) | 主批结果外溢后再议 |
