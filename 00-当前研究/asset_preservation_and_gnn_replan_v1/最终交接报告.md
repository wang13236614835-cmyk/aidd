## 1. 最终判断

本轮没有重做项目，也没有删除历史资产。三个仓库已经统一为：

- AIDD 主库：唯一正式科研结论源；

GNN 仓库裁决为：**小修即可**，不改仓库名、不搬迁目录、不重构旧模型。当前 GNN 状态为 **gated**：代码和历史结果保留，当前不得作为 FASN 主模型或天然产物候选排名来源。

## 3. 哪些旧结果值得保留但不能再作科研证据

- 旧 NumPy GCN：真实实现，保留作传播、梯度、Adam、MC-dropout 学习和错误复盘；
- 旧标签/旧 split/旧预测/旧 Top-10：保留作历史可复现快照，但旧标签不是 MASH assay-level 标签，旧 split 不能证明泛化；
- 旧 FXR/THRβ 模型 artifact：保留作内部模型/方法对照，不能包装成 external validation；
- 2J4A/N331S PDB/PDBQT 与历史 docking：保留作 mutant receptor exploratory 输入和方法学复盘；
- WT docking 日志、pose、raw result：保留作排序门失败证据和结构假说支持；
- 原始 ChEMBL/BindingDB/PDB/天然产物结构、运行日志、模型权重和 manifest：全部保留；
- 旧错误文案和旧 ranking：保留为 REJECTED/HISTORICAL 错误案例，禁止继续解释。

## 4. GNN 库是否需要大改

**小修即可。**

依据：旧代码真实可运行，目录和 Git 历史仍可追踪，数据/模型/日志/工作台均可定位；主要问题是入口文案、状态边界、旧标签、旧 split 和结果用途混杂，而不是架构已经阻碍复现。

本轮已做的小修：

- README 改为方法学习/历史复核/组员工作区；
- 增加 `RESEARCH_STATE.md`、`STATUS.json`、`GNN_RESEARCH_PLAN_v2.md`、审计和状态表；
- 明确旧 Top-10、旧 split、旧标签、docking ranking 的历史/废弃状态；
- 统一 `run_all.py --legacy-demo` 为历史教学复现命令，默认入口只显示未放行状态；
- 保留所有旧目录和公共 API。

只有在 Gate T1 通过、正式 benchmark 数量扩大、且现有路径确实阻碍多模型维护时，才重新考虑中等重构。
