# research_chain_v3 方法学冻结

## 核心原则

1. **先证据资格，再做发现**：疾病/靶点、化合物身份、来源、assay 与文献边界先资格化。
2. **计算不是发布 Gate**：模型、相似性、docking、ADMET 都是上游支持；不能替代直接靶点/功能实验。
3. **三轨并行但不混排**：
   - NEW_LEAD：五个冻结 MCULE；
   - REPURPOSING_NEW_MECHANISM：老药/成熟天然产物的新用途、新机制、新细胞场景；
   - UNDEREXPLORED_DISCOVERY：低/中研究饱和天然产物。
4. **研究成熟度不作为淘汰条件**：高成熟度降低“全新分子”新颖性，但不降低再利用/新机制价值。
5. **反向药理分级**：exact compound / same medicinal-chemistry series / pharmacology reference / unresolved；禁止把同靶点或相似骨架说成同一药或中药来源。
6. **ADORA2A方向保持场景依赖**：agonism/antagonism 不预设为MASH全局正确方向；按HSC、hepatocyte、macrophage/Kupffer和模型拆分。
7. **W0先于湿实验**：actual lot、CoA、purity、exact structure、identity 缺一则 BLOCKED。
8. **W1/W2先确认靶点与方向**：binding + cAMP；无直接活性时不得进入“候选已验证”叙事。
9. **W3/W4按结果扩展**：selectivity/artifact controls → MASH肝细胞场景；必要时才做rescue/knockdown，不提前堆实验。
10. **允许零阳性与负结果**：失败、无活性、方向相反、上下文不一致均保留为正式结果。
11. **人机协同去黑箱**：AI负责覆盖、整理、冲突和任务生成；真人核原始来源、物料和实验；AI不得代签人工review或candidate release。
12. **fail-closed**：v3权威文件缺失/STALE时显示BLOCKED，不静默回退v2。

## 证据层级

- T1：精确身份/直接靶点或功能实验/原始研究。
- T2：同药化系列、明确结构关系和SAR。
- T3：同靶点药理锚点或跨对象机制参考。
- T4：传统用途/网络药理/假说生成，只能导航，不得作核心证明。

## 实验链

W0 物料放行 → W1 ADORA2A binding → W2 cAMP agonist/antagonist → W3 A1/A2B/A3与干扰/毒性 → W4 HSC/hepatocyte/macrophage场景 → 必要时rescue/因果验证。
