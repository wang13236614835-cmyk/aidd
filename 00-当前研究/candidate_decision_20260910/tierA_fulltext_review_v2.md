# A级竞争者全文/摘要证据复核 v2（2026-09-10）

## 结论
A-tier竞争者证据已从检索命中数升级为模型、剂量、终点和机制层级的分层记录。开放全文可核对的重点事实来自 PMCID PMC9231195（Alisol B）、PMC12832275/PMC12869213（Hyperoside）、PMC11261229（Ursolic acid）、PMC10668385（Puerarin）、PMC10218527（Isoquercitrin）。Scoparone、DNJ及部分同类研究仍主要摘要级。

## 关键更新
- **Alisol B**：开放全文显示 100 mg/kg、DIO+CCl4 与 CDA 两种 NASH 模型、n=8、Sirius Red/胶原/α-SMA/Col1a1，CD36/RARα 级联有干预证据；不是直接 RARα/FXR 结合证明。
- **Ursolic acid**：SPP1 有 HuProt+SPR+pull-down+Co-IP+敲低/回补，KD约17.1 μM；支持功能链但不是高亲和力单靶点药效证明。
- **Hyperoside**：FXR/ACLY 有 ITC+对接/MD，但缺少细胞内 target engagement、酶活动力学和暴露桥接；Flot2 为摘要级 CETSA/敲低线索。
- **Puerarin**：开放全文的 HFD+STZ 模型和铁死亡指标较完整，但 200 mg/kg 与 75 μM 没有暴露桥接；SIRT1 对接不等于结合。
- **Isoquercitrin**：MCD 模型有 NAS/Sirius Red/胶原改善，但 HSP90 机制仍是通路/表达与对接，不是物理结合确证。
- **Scoparone**：本体 NASH/MASLD 证据密集，但可获得内容主要为摘要；其“直接结合”表述应限定为 miRNA–mRNA 3′UTR，而非蛋白结合。
- **DNJ**：CDAHFD-MASH/HFD-NASH摘要支持，但剂量、组织学和暴露细节尚未全文核实。

## 证据限制
全文可得不等于研究质量自动高；仍需实验负责人核查随机/盲法、每组独立生物学重复、完整图表、原始数据、统计模型和性别/模型适用性。药物浓度、动物剂量、组织学结果不能直接换算成人体暴露。
