# 研究失败模式树（Week 1冻结版）

## 决策顺序
1. 身份/纯度/溶解性不通过 → 不解释生物学，退回采购与化学核验。
2. 无细胞检测干扰不可排除 → 更换正交读出，不能把报告基因或MTT结果当药效。
3. 无毒窗口内无疾病表型 → 该候选降级，不因对接分数补救。
4. 表型有效但机制干预不影响 → 记录为非该机制表型，不能强行宣称FXR/TRβ/铁死亡。
5. 机制有效但暴露不可达 → 降级为工具化合物/机制探针，进入递送或结构优化分支。
6. A级竞争者全文核查显著强于原三候选 → 并行进入最小验证，不由历史榜单排除。

## 候选分支
- isorhamnetin聚集/干扰 → formononetin前移；scoparone/hyperoside/puerarin进入替代疾病候选评估。
- formononetin FXR桥接失败 → 保留已知FXR/疾病锚，失去新增机制候选地位；对比scoparone/alisol B。
- moracin N只有一般抗氧化 → 不称铁死亡机制，降为方法学对照或退出。
- A级竞争者身份、全文或暴露不通过 → 不自动升级；回到下一级候选。
- ChEMBL模型锁定测试失败 → 模型不参与候选排序，保留为数据审计工具。
- 首选、备选、A类竞争者全部失败或结果不可解释 → 结论为“暂无合格候选”，停止无边界刷分。

## 禁止动作
- 不改阈值、标签方向或验证集直到得到阳性；
- 不把药材/复方/衍生物证据转移给本体；
- 不把通路变化或对接分数写成直接结合/药效；
- 不在供应商规格未核实前采购或开始生物学解释。
