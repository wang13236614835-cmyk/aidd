# 对照体系定义（第六轮冻结）

日期：2026-09-12 ｜ 每个测定中每个化合物的对照角色逐一定义，实验记录按本表打标签

## 一、通用对照（所有板共用）

| 对照 | 内容 | 回答的问题 |
|---|---|---|
| 空白对照 | 无 FFA、无化合物、0.1% DMSO | 基线脂含量与基线读数 |
| 溶媒对照 | 与处理组完全相同的 0.1% DMSO（即空白=溶媒对照，本项目两者合一） | 排除溶媒效应 |
| 模型对照 | PA:OA(1:2) 1 mM、无化合物 | 疾病表型是否建立（整板有效性判据挂钩） |
| 整板有效性 | 模型/空白 TG ≥1.8 且模型活力 ≥70% | 板是否有效；不过则整板作废重做 |

## 三、候选化合物各自的对照角色（冻结）

### Moracin N —— 受试化合物（主线）
全部三级门控的受试对象。无对照角色。读数干扰自查：酚类化合物在 DCFH-DA 板可能直接淬灭/清除荧光 → Gate2 结果解释时附**无细胞体系对照**（DCFH-DA + H2O2 ± MN 10/30 μM，孔板比色，验证 MN 是否直接干扰探针化学），该对照零成本，随 Gate2 同板跑。

### Formononetin —— 受试化合物（支线，仅 FXR 依赖性问题）
只在 FMN 支线当受试对象。**不在 moracin N 主线板中充当任何对照**（两者机制问题不同，混板只会引入解释负担）。

### Biochanin A —— 板级弱活性参照（非阳性对照）
- 唯一角色：Gate1 表型板**同板**加 10 μM 一组，作为"弱活性异黄酮结构参照 + 板级响应检查"——若 BA 与 Fer-1（Gate2）同时无信号而模型有效，提示板/读数灵敏度问题而非化合物问题。
- **禁止**将 BA 用作铁死亡/脂过氧化的阳性对照（它不是）；**禁止**据 BA 结果对 moracin N 做结构类推排序（第五轮已冻结：无综合评分、无类推排序）。
- 采购：平台存量优先；无则小包装 ~¥250（CAS 491-80-5 复核），列扩展档。

### Isorhamnetin —— 书面备选（零采购、零板位）
仅当 moracin N **物料层**失败（买不到/到货不合格/ Gate1 前毒性预筛不过）时按 Go/No-Go 表启用。启用前置条件（预冻结干扰预筛，全部无细胞体系、零细胞成本）：
1. 聚集倾向：吐温-80 敏感性实验（第五轮 isorhamnetin 干扰文献综述已载方法）；
2. DCFH-DA/BODIPY 通道直接干扰（同 moracin N 的无细胞探针对照）；
3. 氧化还原循环风险（儿茶酚结构 → 醌，DCFH-DA 假阳性源）；
4. 任何一项不过 ⇒ 不启用，主假说方向改为书面报告"材料不可行"，不找替补。

### 3'-methoxydaidzein —— 零角色（D 类暂缓）
零采购、零板位、零对照角色。NaV 1.7/1.8/1.3 亚微摩尔脱靶风险（PMID 31262454）未消化前不进入任何活细胞实验。

### Ferrostatin-1 —— 系统阳性对照（非候选）
只作读数系统有效性对照与可选救援参照，永不受试排序。

### ML385 —— 因果工具药（非候选）
只用于 Gate3 Nrf2 阻断与 FMN 支线不涉及。

### T3 / resmetirom —— 仅 THRβ reporter 支线参照
只出现在第八节定义的最小 reporter 裁决板（若导师平台具备），不进入脂毒性主线任何板。

## 四、孔板排布规则

- 每组 ≥3 技术孔，孔位按行随机化（避免边缘效应与位置偏倚），随机表预先登记。
- 外圈孔只充 PBS 防边缘效应，不用于数据。
- 同板必须含空白+模型；跨板比较只通过同板内比值（%模型）进行，禁止直接比较不同板的绝对荧光/吸光度。
