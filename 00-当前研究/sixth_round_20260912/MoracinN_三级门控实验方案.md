# Moracin N 三级门控实验方案（第六轮冻结）

日期：2026-09-12 ｜ 模型：HepG2 + PA:OA(1:2) 总 1 mM + 0.1% DMSO 恒定（见 MASH细胞模型选择.md）
淘汰/晋级阈值在本文件**预冻结**，实验后不得回看数据再改判据。

## 门控总览

```
Gate1 表型门（钱：Gate1 阶段采购 ≈ ¥3419 标准档）
  1a 无模型毒性板 → 1b 模型表型板（TG 主端点 + 油红O 支持端点）
        ↓ 过关
Gate2 机制方向门（钱：+¥850）GSH / DCFH-DA / GPX4 最小集 + Fer-1 系统对照
        ↓ 过关
Gate3 因果门（钱：+¥535）ML385 四组阻断设计 → Nrf2 依赖性裁决
```

每关之间是**采购闸门**：上一关不过关，下一关的钱不下单。Gate1 失败最大沉没成本 ¥3419（标准档）。

## Gate1 表型门

### 1a 无模型毒性板（先跑）
- 分组：空白（0.1% DMSO）+ moracin N 0.1/0.3/1/3/10/30 μM，24 h，CCK-8，3 技术孔×3 生物学重复。
- 通过线：30 μM 活力 ≥ 80%（活力不达标的最高浓度成为实际上限）。

### 1b 模型表型板
- 分组：空白 / 模型（PA:OA）/ 模型+MN 六个浓度（沿用 1a 达标点）。
- 端点：**TG 试剂盒（主端点，蛋白归一）** + 油红O 染色（支持端点，保留代表性图像）。
- 整板有效性：模型/空白 TG 比 ≥1.8 且模型活力 ≥70%，否则整板作废重做。

### Gate1 预冻结判据
- **晋级**：≥2 个相邻无毒性浓度使 TG 较模型组下降 ≥25%，且在独立生物学重复中方向一致（第二次重复在下一周完成）。
- **淘汰（化合物出局）**：无任何无毒性浓度达到 ≥15% TG 下降；或 ≤10 μM 即活力 <80%。
- 15%-25% 之间：不加结论，补第三个生物学重复后按多数方向判定，仍骑墙则按淘汰处理（本科预算不允许中间态消耗）。

## Gate2 机制方向门（H2：Nrf2/抗铁死亡方向）

使用 Gate1 筛出的 2-3 个有效浓度。

### 读数最小集（三选二为最低要求，全三为标准）
1. **GSH**（碧云天 S0053，微孔板法）
2. **ROS**（DCFH-DA，酶标仪/流式读 DCF 荧光）
3. **GPX4 蛋白**（western blot，仅当导师平台有一抗；平台无则此项记 not assessed，不采购抗体进标准档）

### 分组
空白 / 模型 / 模型+MN（Gate1 有效浓度点）/ 模型+Ferrostatin-1 1 μM（**读数系统阳性对照，Fer-1 无效则本批 Gate2 无效**）。
erastin（若平台有存量）：只作为读数系统正向参照（模型外孔），不进入 MN 比较。

### Gate2 预冻结判据
- **晋级**：≥2 个读数较模型组显著改善（预注册统计检验，见实验统计预注册.md），且 Fer-1 对照有效。
- **淘汰（H2 主张出局）**：0 个读数改善（此时 moracin N 作为"Nrf2/抗铁死亡方向候选"出局；若 Gate1 表型扎实，可保留为"表型候选、机制不明"，但不得再消耗 Gate3 预算）。
- 只有 1 个读数改善：如实记录为"机制方向证据不足"，Gate3 不做（ML385 只在有 ≥2 读数改善时才有解释力）。

### C11-BODIPY 的位置
脂质过氧化直接探针 C11-BODIPY（Thermo D3861 ¥1580/mg）**不在标准档**；仅在导师平台流式可用且预算进入扩展档时加做。GSH+ROS+GPX4 已构成可裁决最小集。

## Gate3 因果门（Nrf2 依赖性，单一决定性实验）

### 四组设计
| 组 | FFA | MN | ML385 5 μM |
|---|---|---|---|
| G1 模型 | + | − | − |
| G2 MN | + | 最有效浓度 | − |
| G3 ML385 | + | − | + |
| G4 MN+ML385 | + | 最有效浓度 | + |

- 主端点：Gate1/2 中 MN 效应量最大的读数（默认 TG；若 Gate2 读数效应更大则用该读数，**开板前登记，不得事后换**）。
- ML385 单独组（G3）活力须 ≥80%，否则本批无效；降 2.5 μM 重试一次，再失败则 Gate3 记 not assessed（机制门保持开放，如实报告，不得写成 Nrf2 不依赖）。
- 可选第五组：模型+Fer-1 1 μM（对照锚，确认本批铁死亡/脂过氧化成分仍可干预）。

### Gate3 预冻结解释（削减率 = 1 − 效应量[G4−G1] / 效应量[G2−G1]，效应量=相对模型组的改善）
| 结果 | 判定 | 允许的表述 |
|---|---|---|
| 削减 ≥70% | Nrf2 依赖性支持 | "在 HepG2 脂毒性模型中，ML385 阻断提示 moracin N 的保护效应主要经 Nrf2 通路" |
| 削减 <30% | "Nrf2 为主要介质"主张失败 | "ML385 未能明显削弱其保护效应，Nrf2 非主要介质（或阻断不足）；候选保留为表型候选，机制待查" |
| 30-70% | 部分依赖 | 如实报告"部分依赖"，禁止外推为"主要经 Nrf2" |

### 复合物失败 ≠ 机制失败（全局规则）
- MN 无表型（Gate1 淘汰）→ **该候选在本模型出局**（化合物失败）。
- MN 有表型但 ML385 不削减 → **机制主张失败，候选不连带出局**（表型候选、机制重开）。
- 两者都写进 Go_NoGo决策表.md，禁止混用。
